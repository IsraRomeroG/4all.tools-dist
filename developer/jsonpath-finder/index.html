How to use this Finder

Paste JSON and enter a query, then choose Find. Editing either field clears the previous results. The local example can be loaded whenever you need it.

Version 1 supports the root ($), simple dot properties, double-quoted bracket properties, non-negative array indexes, wildcards (*), and basic recursive descent (..property or ..*). Filters, slices, unions, negative indexes, and single-quoted properties are not supported.

Choose a result to reveal its complete path and copy actions. Arrays are visited by increasing index; object properties follow their order in this input. That order is a Finder behavior, not a universal JSONPath ordering rule.

Limits: 1,000,000 JSON UTF-16 code units, 200 nested levels, 100,000 JSON values, 100 diagnostics, 1,000,000 parser work units, 512 query UTF-16 code units, 32 query steps, 500,000 query work units, 200 visible matches, 1,000,000 result text code units, and 200,000 code units per copied value. An operation stops after 15 seconds. When more than 200 matches exist, the total is not calculated.

      Find values in a JSON document

      Paste one complete strict JSON value and enter a query. Search starts only after you choose Find. Editing either field clears the displayed results; choose Cancel to stop a search while keeping both fields unchanged. The local example loads the same document and query shown here:

      {"users":[{"name":"Ana"},{"name":"Beto"}],"a.b":null}

      For $.users[*].name, the Finder returns $.users[0].name with preview "Ana", followed by $.users[1].name with preview "Beto". The query $.missing is valid and returns no matches. The root query $ selects the whole document, including an empty object {} or array [].

      Supported JSONPath syntax

      Version 1 supports the root $, simple dot properties such as $.users, double-quoted bracket properties such as $["a.b"], non-negative array indexes such as $.users[0], the child wildcard *, and basic recursive descent such as $..name and $..*. Filters, slices, unions, negative indexes, and single-quoted property names are not supported.

      The results follow the order used by this Finder: array indexes increase from zero, and object properties follow their order in the input file. Object ordering is not a universal JSONPath guarantee. Each result shows a complete path, value type, and bounded text preview. Select a result to reveal its full path and the Copy path and Copy JSON value actions. A number precision warning stays visible before copying when the parser detects possible loss of precision.

      Result and browser limits

      The Finder displays at most 200 matches. If it observes a 201st match, it stops and reports that more exist; it does not calculate or claim a total. When a query exceeds its work budget, it returns an error without partial results. Copying a JSON value is a separate Worker request capped at 200,000 UTF-16 code units. A value over that limit is not copied and the selection is kept. The visible interface also reports its input, query, parsing, result, and time limits.

      Your JSON and query are processed in this browser. They are not placed in the URL, saved in browser storage, or sent to a server. JSON Formatter & Validator can check or format the input first; JSON Diff compares two documents when you need to inspect changes.
