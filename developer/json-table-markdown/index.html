View a JSON array as a table and export Markdown

Choose an array of objects, select literal columns and export a safe GFM Markdown table locally in your browser.

Tool workspace

JSON Table / JSON to Markdown

Enable JavaScript to use this local tool.

Choose an array of objects explicitly. Strings and headers use JSON quotes; line breaks stay as escapes. ∅ means a missing property, distinct from null and "". Objects and arrays appear as compact JSON; columns keep literal keys and source order.

Your document is processed locally in your browser. No uploads, remote documents or saved input.

      Choose your array and columns

      Paste strict JSON or open one UTF-8 .json file, then press Analyze arrays. Select a source array explicitly, even when it is the root $, and press Inspect columns. Arrays are listed by literal typed paths and pages. Every row must be an object, including rows you later omit. Decoded duplicate keys, JSONC, JSON5 and invalid UTF-8 are rejected. Valid JSON without arrays has its own empty state; [] and arrays of empty objects have no columns.

      The column union covers every row in source order, including late keys. Select a nonempty subset and use Move up/down to choose export order. Empty keys, numeric keys, dots, brackets, Unicode and __proto__ remain literal. [{"":null,"10":1,"2":2},{"2":3,"late":true}] discovers "", "10", "2", "late" in that order. Nested objects are cells; they are not flattened.

      Read the same cells in both outputs

      [{"id":"00123","name":"Ana"},{"name":"Beto","active":true}]

      The default columns are id, name, active. The first row displays "00123", "Ana", ∅; the second displays ∅, "Beto", true. Strings and headers keep JSON quotes. A missing property is ∅, null is null, and an empty string is "". Line breaks and controls stay as JSON escapes. Nested objects and arrays use compact JSON with source member order. Numbers preserve spellings such as 1.0, 1e0, -0 and 9007199254740993, including inside nested cells. A precision warning describes the parser’s approximate internal value; overflow such as 1e999 is rejected.

      Choose all rows or the first positive N rows. This intentional omission is reported separately; column discovery still covers the entire array. Prepare table creates the selected result. Pages of 10/25/50 rows show a real range and can be shorter due to width or text budgets. Paging never changes the rows exported.

      Generate, copy and download Markdown

      Press Generate Markdown to export every included row from the same prepared cells. The target is GitHub Flavored Markdown tables with numeric entities. ASCII punctuation is encoded deliberately: a data pipe becomes &#124;, and quotes become &#34;. HTML, image and Markdown syntax is escaped while preserving the text. A Markdown viewer may turn URLs or email addresses into clickable links after decoding the entities. The local table displays text only. JSON line escapes remain visible. The Markdown source may be longer than the visible table. No Markdown renderer runs in the tool.

      Copy takes the complete output; when clipboard access fails, select the readonly output field and copy manually. Download produces the same text as json-table.md, UTF-8 without BOM, with LF line endings and a final LF. A Markdown expansion limit keeps the valid table but offers no partial export. Markdown is not reversible JSON and compatibility with every Markdown dialect is not promised.

      Local processing and limits

      JavaScript and a local Worker are required. Input and output are never uploaded or saved in storage, logs or URLs. Related tools open without transferring the document. Input, array, column or row-limit changes invalidate results; page size changes preserve export. Cancel terminates the Worker, and retry analyzes the current source again. A rejected file keeps previous editor text. One initial BOM is visibly removed for parsing; a second initial BOM is invalid.

      Files allow 4,000,000 bytes; input 1,000,000 UTF-16 units; depth 200; source nodes 100,000; rows 20,000; union columns 200; column keys 1,000 units; included cell positions 75,000. Cell text allows 10,000 units, headers 20,000, each row 100,000, complete table 1,000,000 and Markdown 2,000,000. A visible page mounts at most 50 rows, 2,500 cells and 200,000 text units. Parsing and structural work also have hard budgets; not all maxima can be accepted simultaneously. Hard limits fail without partial tables or truncated cells. There is no cell editing, filtering, row sorting, manual schema, flattening, repair, CSV extension, XLSX or HTML export.
