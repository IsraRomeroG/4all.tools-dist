Formatea, embellece y valida JSON online. Detecta errores de sintaxis y facilita la lectura de tus datos JSON.

Guía y límites del JSON
  • Las propiedades duplicadas producen una advertencia; el último valor es el efectivo.
  • Los enteros grandes pueden perder precisión porque los números JSON usan valores numéricos de JavaScript.
  • Los límites de entrada, anidación, nodos, procesamiento, salida y tamaño de archivo protegen el navegador. Los límites de texto usan unidades UTF-16; los de archivo usan bytes.
  • Las firmas BOM UTF-8 se rechazan. El texto pegado se conserva exactamente como se introduce, sin recortarlo ni normalizarlo.

Las operaciones JSON se procesan localmente en tu navegador y no se envían a un servidor durante el uso.

Formateador JSON

Un formateador JSON añade sangría y saltos de línea sin cambiar la estructura analizada. «Embellecer», prettify y pretty print describen la misma operación. Elige 2 espacios, 4 espacios o tabulaciones y usa Formatear y validar JSON para comprobar la sintaxis y crear un resultado legible.

Este es un JSON válido que se puede formatear:

{
  "name": "4all.tools",
  "active": true,
  "score": 42,
  "notes": null,
  "archived": false
}

Validador JSON

El validador comprueba la sintaxis JSON estándar. Detecta errores como comas faltantes o finales, cadenas con comillas simples, comentarios, propiedades sin comillas y llaves o corchetes sin cerrar. Cuando el navegador ofrece una posición útil, el diagnóstico incluye línea, columna y contexto cercano.

Este ejemplo no es válido porque falta una coma tras la primera propiedad:

{
  "name": "4all.tools"
  "active": true
}

Validar la sintaxis no equivale a validar con JSON Schema. Validar JSON comprueba si el texto se puede analizar como JSON estándar; no aplica propiedades obligatorias, tipos de datos ni otras reglas de un esquema, y no repara automáticamente la entrada.

Cómo formatear JSON online

  1. Pega JSON en Entrada o carga un archivo .json permitido.
  2. Elige una sangría de 2 espacios, 4 espacios o tabulaciones.
  3. Selecciona Formatear y validar JSON.
  4. Revisa Resultado. Una entrada válida genera JSON formateado; si es inválida, permanece en Entrada y muestra un diagnóstico cuando hay ubicación.
  5. Copia Resultado o descarga el archivo JSON formateado actual.

Cómo validar JSON online

  1. Pega o carga el JSON que quieres comprobar.
  2. Selecciona Validar JSON sin necesidad de formatearlo.
  3. Busca el estado JSON válido o revisa el diagnóstico de sintaxis.
  4. Si hay línea, columna y contexto, úsalos para corregir Entrada y vuelve a validar.

Minificador JSON

Minificar JSON analiza una entrada válida y la serializa como JSON compacto en una sola línea. La minificación elimina espacios de formato; no comprime el archivo ni crea un ZIP u otro formato de archivo. El resultado actual se puede copiar o descargar.

Procesamiento local en el navegador

El formateo, la validación, la minificación, la lectura de archivos, la copia y la preparación de la descarga ocurren localmente en tu navegador. Durante esas operaciones, el JSON no se envía a un servidor de la aplicación ni se almacena de forma remota mediante esta herramienta.

Preguntas frecuentes

¿Qué hace un formateador JSON?

Analiza JSON y lo serializa con sangría y saltos de línea coherentes para que su estructura sea más fácil de leer.

¿Cómo puedo formatear JSON online?

Pega o carga JSON, elige la sangría y selecciona Formatear y validar JSON. Si la sintaxis es válida, el texto legible aparece en Resultado.

¿Cómo valido JSON y localizo errores de sintaxis?

Selecciona Validar JSON. Una entrada inválida muestra un diagnóstico y, cuando el navegador proporciona una posición recuperable, su línea, columna y contexto.

¿Cuál es la diferencia entre formatear y validar JSON?

Validar solo comprueba la sintaxis. Formatear también valida y después genera un resultado con la sangría elegida.

¿Puedo cargar un archivo .json?

Sí. Selecciona o arrastra un archivo .json permitido para llevar su texto a Entrada y procesarlo localmente.

¿Cómo minifico JSON en una sola línea?

Introduce JSON válido y selecciona Minificar JSON. Resultado contendrá el JSON serializado de forma compacta en una línea.

¿Mi JSON se envía a un servidor?

No. La herramienta realiza sus operaciones JSON localmente en el navegador y no envía el contenido a un servidor de la aplicación durante el uso.

¿Esta herramienta valida con JSON Schema?

No. Solo valida la sintaxis JSON estándar y no aplica un JSON Schema.

Limitaciones del análisis JSON

La herramienta usa su analizador y serializador JSON de producto con límites de seguridad explícitos. Los enteros muy grandes pueden perder precisión al representarse como números de JavaScript. Las claves duplicadas producen una advertencia y el último valor es efectivo. Por ello, serializar de nuevo puede cambiar el texto exacto y no garantiza conservar exactamente todos los valores originales.

Se rechaza una firma BOM UTF-8 y el texto pegado no se recorta ni normaliza antes del análisis estricto. Una entrada vacía o formada solo por espacios JSON devuelve EMPTY_INPUT. El texto pegado está limitado a 5.242.880 unidades UTF-16; la profundidad, los nodos, el trabajo y la salida también están limitados por el perfil de seguridad seleccionado. Las funciones de JSON5, los comentarios, las comas finales, las cadenas con comillas simples, NaN, Infinity y undefined no pertenecen al JSON estándar y se rechazan como entrada. Los escapes de sustitutos aislados se aceptan con advertencias, y formatear o minificar cambia los espacios y no conserva la representación textual original.

La herramienta separa el estado de la operación de la validez del documento. Informa por separado del desbordamiento numérico, las propiedades duplicadas rechazadas, los límites superados, la cancelación y los fallos de copia o descarga. El panel de ayuda también explica los duplicados, la precisión numérica, las unidades de los límites de texto y archivo y la política de BOM UTF-8 rechazado.
