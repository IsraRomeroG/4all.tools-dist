Cómo usar este buscador

Pega JSON e introduce una consulta; después, elige Buscar. Si editas cualquiera de los campos, se eliminan los resultados anteriores. Puedes cargar el ejemplo local cuando quieras.

La versión 1 admite la raíz ($), propiedades simples con punto, propiedades entre corchetes y comillas dobles, índices de array no negativos, comodines (*) y descenso recursivo básico (..propiedad o ..*). No admite filtros, slices, uniones, índices negativos ni propiedades entre comillas simples.

Elige un resultado para ver su ruta completa y las acciones de copia. Los arrays se recorren por índice ascendente; las propiedades de objetos siguen el orden del archivo de entrada. Ese orden es propio de este buscador, no una regla universal de JSONPath.

Límites: 1.000.000 unidades UTF-16 de JSON, 200 niveles de anidamiento, 100.000 valores JSON, 100 diagnósticos, 1.000.000 unidades de trabajo del analizador, 512 unidades UTF-16 de consulta, 32 pasos, 500.000 unidades de trabajo de consulta, 200 coincidencias visibles, 1.000.000 unidades de texto en resultados y 200.000 unidades por valor copiado. Cada operación se detiene tras 15 segundos. Si hay más de 200 coincidencias, no se calcula el total.

{"users":[{"name":"Ana"},{"name":"Beto"}],"a.b":null}

      Busca valores en un documento JSON

      Pega un único valor JSON estricto y completo y escribe una consulta. La búsqueda comienza al elegir Buscar. Si editas cualquiera de los campos, se eliminan los resultados visibles; elige Cancelar para detener una búsqueda sin cambiar las entradas. El ejemplo local carga el mismo documento y la misma consulta que aparecen aquí:

      {"users":[{"name":"Ana"},{"name":"Beto"}],"a.b":null}

      La consulta $.users[*].name devuelve primero $.users[0].name, con la vista previa "Ana", y después $.users[1].name, con la vista previa "Beto". La consulta $.missing es válida y no devuelve coincidencias. La consulta raíz $ selecciona el documento completo, incluidos un objeto {} o un array [] vacíos.

      Sintaxis JSONPath admitida

      La versión 1 admite la raíz $, propiedades simples con punto como $.users, propiedades entre corchetes y comillas dobles como $["a.b"], índices de array no negativos como $.users[0], el comodín de hijos * y descenso recursivo básico como $..name y $..*. No admite filtros, slices, uniones, índices negativos ni nombres de propiedad entre comillas simples.

      Los resultados siguen el orden de este buscador: los índices de arrays recorren desde cero en orden ascendente y las propiedades de objetos siguen el orden en que aparecen en el archivo de entrada. El orden de las propiedades no es una garantía universal de JSONPath. Cada resultado muestra una ruta completa, el tipo del valor y una vista previa de texto acotada. Selecciona un resultado para ver su ruta completa y las acciones Copiar ruta y Copiar valor JSON. Si el analizador detecta una posible pérdida de precisión, el aviso permanece visible antes de copiar.

      Límites de resultados y del navegador

      El buscador muestra como máximo 200 coincidencias. Si detecta la coincidencia 201, se detiene e indica que hay más; no calcula ni afirma un total. Si una consulta supera su presupuesto de trabajo, devuelve un error sin resultados parciales. Copiar un valor JSON es una solicitud independiente al Worker, con un límite de 200.000 unidades de código UTF-16. Los valores que superan ese límite no se copian y la selección se conserva. La interfaz indica también los límites de entrada, consulta, análisis, resultados y tiempo.

      Tu JSON y tu consulta se procesan en este navegador. No se colocan en la URL, no se guardan en el almacenamiento del navegador ni se envían a un servidor. Formateador y validador JSON puede comprobar o formatear la entrada antes; Comparador JSON compara dos documentos para revisar sus diferencias.
