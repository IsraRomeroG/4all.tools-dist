Buscar claves y valores en JSON

Encuentra texto literal en claves y valores primitivos de JSON estricto, copia la ruta o localiza el valor original en tu navegador.

Espacio de trabajo de la herramienta

Buscar en JSON

Activa JavaScript para buscar localmente en tu navegador.

Busca claves decodificadas y valores primitivos. Texto completo significa igualdad textual: 1 difiere de 1.0 y 1e0. Espacios, comillas y saltos de línea de la consulta son literales. Ignorar mayúsculas usa minúsculas de JavaScript sin retirar acentos ni normalizar Unicode. No interpreta regex ni JSONPath.

Entrada: 1.000.000 unidades UTF-16; archivo: 4.000.000 bytes; consulta: 1000 unidades; profundidad: 200; nodos: 100.000; resultados: 1000; filas por página: 50.

Opciones de búsqueda

Presupuesto de texto: 5.000.000 unidades UTF-16; cada ruta: 10.000; rutas retenidas: 2.000.000. Parseo: 1.000.000 unidades de trabajo; índice: 100.000 visitas; búsqueda: 100.000 visitas. Tiempo de búsqueda: 15.000 ms; página/navegación: 3000 ms. Texto y rutas pueden agotar el presupuesto aunque tamaño y nodos estén dentro del límite.

El JSON, la consulta y los resultados permanecen en esta pestaña. No se suben ni se guardan.

Cargar ejemplo
{
  "name": "Ana",
  "nickname": "Anabel",
  "Ana": "Ana",
  "active": true,
  "note": null,
  "items": [
    { "name": "ANA", "price": 1.0 },
    { "a.b": "banana", "empty": {} }
  ]
}

El ejemplo con «Ana» y las opciones iniciales encuentra $.name, $.nickname y $.Ana. Cárgalo y pulsa Buscar.

Opciones de búsqueda

      Busca texto literal con una acción explícita

      Pega JSON estricto o abre un archivo .json UTF-8. Introduce texto literal y pulsa Buscar. Las opciones iniciales buscan en claves y valores, con texto parcial y sensibilidad a mayúsculas. Espacios, tabs, saltos, comillas, barras inversas y caracteres de regex son datos: la consulta no se recorta, no se decodifica como JSON ni se interpreta como regex, comodines o JSONPath. La consulta vacía se rechaza; un espacio es válido.

      Claves y strings se buscan después de decodificar sus escapes JSON. Los valores buscables son strings, números, booleanos y null. Los objetos y arrays se recorren sin buscar su representación serializada; la clave de un contenedor sí puede coincidir. Índices de arrays y componentes de ruta no son claves buscables. Una raíz primitiva es válida con ruta $; los contenedores vacíos producen éxito sin coincidencias.

      Prueba el ejemplo compartido

      {
  "name": "Ana",
  "nickname": "Anabel",
  "Ana": "Ana",
  "active": true,
  "note": null,
  "items": [
    { "name": "ANA", "price": 1.0 },
    { "a.b": "banana", "empty": {} }
  ]
}

      Cargar ejemplo adopta Ana y restablece las opciones; luego pulsa Buscar. Con defaults aparecen $.name, $.nickname y $.Ana. Texto completo encuentra $.name y $.Ana: Ana solo encuentra Anabel en parcial. Parcial sin sensibilidad añade $.items[0].name y $.items[1]["a.b"]. Claves/completa encuentra solo $.Ana; valores/completa sin sensibilidad encuentra $.name, $.Ana y $.items[0].name. La coincidencia de clave y valor en $.Ana produce una fila con ambos indicadores.

      Igualdad textual, tipos y escritura numérica

      Buscar null encuentra null y el string "null"; cada fila muestra su tipo. Los números usan su lexema original: 1, 1.0, 1e0 y -0 son textos distintos. En el ejemplo, valores/completa con 1 no encuentra coincidencias; parcial encuentra el precio. Un entero como 9007199254740993 se busca sin redondearlo; el aviso de precisión describe la aproximación interna de JavaScript. Los números fuera del rango finito admitido se rechazan.

      Ignorar mayúsculas aplica toLowerCase() de JavaScript, independientemente del idioma. No elimina acentos, normaliza Unicode ni implementa plegado completo: ÁRBOL coincide con árbol, pero arbol no; Straße difiere de STRASSE, İ de i, y É de e seguido de U+0301. Rutas y vistas previas conservan su escritura original.

      Navega, copia e interpreta los límites

      Los resultados siguen el orden fuente, con una fila por nodo. El botón de ruta selecciona el valor completo en el editor original, también si coincidió su clave. No cambia el JSON. Se muestran ruta y línea/columna; Volver al resultado restaura el foco. Copiar ruta copia su texto completo y ofrece copia manual si falla el portapapeles. Las vistas previas acortadas de clave/valor tienen indicadores propios.

      Se retienen hasta 1.000 resultados y páginas de 50. Exactamente 1.000 es un total completo si termina el recorrido; descubrir la coincidencia 1.001 produce «al menos 1.001», con total exacto desconocido. Solo se paginan resultados retenidos. JSON inválido, claves decodificadas duplicadas como {"a":1,"\u0061":2} o presupuestos duros agotados no producen lista; son distintos de cero coincidencias. No admite JSONC, JSON5, reparación ni reemplazo.

      Archivo: 4.000.000 bytes; entrada original: 1.000.000 unidades UTF-16; consulta: 1.000; profundidad de contenedores: 200; nodos: 100.000. El texto comparado tiene presupuesto de 5.000.000 unidades, cada ruta de 10.000 y las rutas retenidas de 2.000.000. Pueden agotarse antes de tamaño/nodos. Búsqueda: 15 segundos; página/navegación: 3 segundos. Se ignora una firma BOM inicial con aviso y se mantienen los rangos originales al navegar.

      Todo se procesa localmente en memoria. Archivo y copia requieren acciones explícitas; no se suben datos ni se guardan en URLs o almacenamiento del navegador. Editar entrada, consulta u opciones, cargar archivo/ejemplo o limpiar retira resultados anteriores. Cancelar conserva entrada y opciones. Requiere JavaScript y Workers locales. Los relacionados abren normalmente sin transferir tu documento.
