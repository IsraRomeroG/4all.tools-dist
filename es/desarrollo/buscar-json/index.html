Buscar claves y valores en JSON

Busca texto en claves y valores JSON. Ajusta la coincidencia, revisa los resultados y localiza cada valor en el documento original.

Espacio de trabajo de la herramienta

Buscar en JSON

Activa JavaScript para buscar localmente en tu navegador.

Busca claves decodificadas y valores primitivos. Texto completo significa igualdad textual: 1 difiere de 1.0 y 1e0. Espacios, comillas y saltos de línea de la consulta son literales. Ignorar mayúsculas usa minúsculas de JavaScript sin retirar acentos ni normalizar Unicode. No interpreta regex ni JSONPath.

Entrada: 1.000.000 unidades UTF-16; archivo: 4.000.000 bytes; consulta: 1000 unidades; profundidad: 200; nodos: 100.000; resultados: 1000; filas por página: 50.

Opciones de búsqueda

Presupuesto de texto: 5.000.000 unidades UTF-16; cada ruta: 10.000; rutas retenidas: 2.000.000. Parseo: 1.000.000 unidades de trabajo; índice: 100.000 visitas; búsqueda: 100.000 visitas. Tiempo de búsqueda: 15.000 ms; página/navegación: 3000 ms. Texto y rutas pueden agotar el presupuesto aunque tamaño y nodos estén dentro del límite.

El JSON, la consulta y los resultados permanecen en esta pestaña. No se suben ni se guardan.

Cargar ejemplo
{
  "name": "Ana",
  "nickname": "Anabel",
  "Ana": "Ana",
  "active": true,
  "note": null,
  "items": [
    { "name": "ANA", "price": 1.0 },
    { "a.b": "banana", "empty": {} }
  ]
}

El ejemplo con «Ana» y las opciones iniciales encuentra $.name, $.nickname y $.Ana. Cárgalo y pulsa Buscar.

      Busca una clave o un valor

      Pega JSON estricto o abre un archivo .json UTF-8. Escribe el texto que quieres encontrar y pulsa Buscar. Por defecto, se busca en claves y valores, se aceptan coincidencias parciales y se distinguen mayúsculas de minúsculas.

      La búsqueda interpreta el texto literalmente. No usa expresiones regulares, comodines ni JSONPath. Un espacio cuenta como consulta; una consulta vacía no se admite. Los escapes JSON de las claves y cadenas se decodifican antes de compararlos.

      Se buscan cadenas, números, booleanos y null. Los objetos y arrays se recorren para buscar en su contenido, pero no se comparan como bloques de texto. Sus nombres de propiedad sí pueden coincidir; los índices de arrays no se buscan como claves.

      Prueba las opciones con este ejemplo

      {
  "name": "Ana",
  "nickname": "Anabel",
  "Ana": "Ana",
  "active": true,
  "note": null,
  "items": [
    { "name": "ANA", "price": 1.0 },
    { "a.b": "banana", "empty": {} }
  ]
}

      Cargar el ejemplo establece la consulta Ana y restablece las opciones. Pulsa Buscar para ver los resultados.

      Opciones Rutas encontradas
      Predeterminadas $.name, $.nickname, $.Ana
      Coincidencia completa $.name, $.Ana
      Parcial, sin distinguir mayúsculas Las predeterminadas, más $.items[0].name y $.items[1]["a.b"]
      Solo claves, coincidencia completa $.Ana
      Solo valores, completa, sin distinguir mayúsculas $.name, $.Ana, $.items[0].name

      Ana coincide con Anabel solo en búsqueda parcial. En $.Ana coinciden tanto la clave como el valor, por lo que se muestra una fila con ambos indicadores.

      El texto importa, también en los números

      Buscar null encuentra tanto el valor null como la cadena "null"; el tipo de cada resultado permite distinguirlos. Los números se comparan tal como están escritos: 1, 1.0, 1e0 y -0 son textos distintos. En el ejemplo, buscar el valor completo 1 no encuentra el precio 1.0; una búsqueda parcial sí.

      Los enteros grandes, como 9007199254740993, se buscan sin redondear su texto. Un aviso de precisión describe su representación interna, no un cambio en la búsqueda. Los números fuera del rango finito admitido se rechazan.

      Ignorar mayúsculas no elimina acentos ni iguala todas las variantes Unicode. ÁRBOL coincide con árbol, pero no con arbol; Straße no coincide con STRASSE. Las rutas y las vistas previas conservan la escritura original.

      Revisa y localiza las coincidencias

      Los resultados siguen el orden del documento, con una fila por valor. El botón de ruta selecciona el valor completo en la entrada, incluso cuando la coincidencia está en su clave. Puedes consultar la línea y la columna, usar Copiar ruta o regresar con Volver al resultado.

      Se muestran hasta 1.000 resultados, en páginas de 50. Si hay más, el informe indica «al menos 1.001» y no calcula el total exacto. Las vistas previas pueden acortarse; copiar una ruta siempre entrega su texto completo.

      Una entrada inválida no equivale a una búsqueda sin coincidencias. Los comentarios, JSONC, JSON5 y las claves duplicadas se rechazan. La herramienta no reemplaza valores.

      Límites y privacidad

      Límite Máximo
      Archivo 4.000.000 bytes
      Entrada 1.000.000 unidades UTF-16
      Consulta 1.000 unidades UTF-16
      Contenedores anidados / valores 200 niveles / 100.000
      Una ruta 10.000 unidades UTF-16
      Tiempo de búsqueda 15 segundos

      Las rutas extensas o una búsqueda compleja pueden alcanzar otros límites antes. Si se supera un límite de procesamiento, no se entrega una lista parcial. Un BOM inicial se omite con aviso.

      La búsqueda se realiza en un Worker local y necesita JavaScript. No se suben ni se guardan los documentos. Editar la entrada, la consulta o las opciones retira los resultados anteriores; cancelar conserva la entrada. Los enlaces a herramientas relacionadas abren otra página sin enviarle tu documento.
