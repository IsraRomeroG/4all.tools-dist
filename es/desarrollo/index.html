Herramientas para Desarrolladores

Utilidades para desarrolladores que trabajan con formatos de datos, codificadores, generadores y tecnologías web.

Herramientas

  • Analizador de tamaño JSON

    Mide bytes UTF-8 exactos, longitud UTF-16, nodos, arrays y rutas con análisis local de JSON estricto.

  • Aplanar / Reconstruir JSON

    Convierte JSON estricto en rutas reversibles con puntos o corchetes y reconstruye mapas localmente, conservando vacíos y tokens numéricos y rechazando ambigüedades.

  • Buscador JSONPath

    Busca en un documento JSON estricto con una consulta JSONPath admitida, revisa rutas y vistas previas y copia una ruta o un valor desde el navegador.

  • Buscar en JSON

    Encuentra texto literal en claves y valores primitivos de JSON estricto, copia la ruta o localiza el valor original en tu navegador.

  • Comparador de JSON

    Compara dos documentos JSON estrictos por sus valores. Revisa altas, bajas y cambios con diagnósticos localizados y vistas previas acotadas.

  • Conversor JSON ↔ XML

    Convierte JSON estricto y un subconjunto de datos XML 1.0 localmente, con raíces explícitas, atributos, elementos repetidos y avisos de pérdidas.

  • Convertidor de JSON a CSV

    Convierte arrays de objetos JSON a CSV o inspecciona encabezados CSV y transforma filas a JSON con opciones explícitas de tipos y filas irregulares.

  • Convertidor JSON / SQL

    Convierte filas JSON planas a un subconjunto SQL documentado de PostgreSQL o SQLite, o importa CREATE TABLE e INSERT admitidos como JSON.

  • Convertidor JSON ↔ YAML

    Convierte JSON estricto a YAML o un subconjunto YAML compatible con JSON a JSON, conservando orden de miembros y escritura numérica en tu navegador.

  • Formateador y Validador JSON

    Formatea, embellece y valida JSON online. Detecta errores de sintaxis y facilita la lectura de tus datos JSON.

  • Generador de JSON Schema

    Infiere un esquema común desde una a veinte muestras JSON, revisa campos requeridos y comprueba cada documento completo localmente.

  • JSON a C#

    Infiere clases C# localmente con claves JSON exactas, presencia mediante JsonRequired y capacidades explícitas de nullable y números raw.

  • JSON a Go

    Infiere structs y mapas raw de Go localmente, conserva los lexemas numéricos con json.Number y conoce las capacidades de los punteros opcionales.

  • JSON a Python

    Infiere declaraciones TypedDict localmente, conserva las claves exactas y distingue campos ausentes de None.

  • JSON a TypeScript

    Infiere tipos TypeScript desde documentos JSON completos, conserva claves literales y distingue ausencia de null localmente.

  • Ordenar claves JSON

    Ordena claves de JSON estricto en ascendente o descendente, de forma recursiva o solo en la raíz, conservando arrays y números originales localmente.

  • Reparador JSON

    Convierte comentarios y comas finales de JSONC a JSON estricto o intenta reparar errores comunes con heurísticas acotadas y cambios revisables.

  • Tabla JSON / JSON a Markdown

    Elige un array de objetos, selecciona columnas literales y exporta una tabla Markdown GFM segura localmente en tu navegador.

  • Validador de JSON Schema

    Comprueba un documento JSON estricto con un subconjunto local y limitado de JSON Schema draft-07.

  • Visor de árbol JSON

    Explora JSON estricto como un árbol expandible y acotado. Inspecciona tipos, pagina arrays grandes y copia una ruta JSON mientras la entrada permanece en tu navegador.
