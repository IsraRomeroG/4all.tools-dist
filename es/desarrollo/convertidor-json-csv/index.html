Convierte JSON y CSV en tu navegador

Convierte arrays de objetos JSON a CSV o inspecciona encabezados CSV y transforma filas a JSON con opciones explícitas de tipos y filas irregulares.

Espacio de trabajo de la herramienta

Convertir JSON a CSV y CSV a JSON

Dirección de conversión

Elige un array de objetos después de inspeccionarlo. La entrada no se modifica.

Ejemplo reproducible

{
  "people": [
    { "name": "Ada", "active": true, "score": 42 },
    { "name": "Grace", "score": null }
  ]
}
Opciones de salida y análisis

Selección de array

Columnas CSV

    Este array no tiene propiedades de objetos para usar como columnas.

    Para un array vacío, añade uno o más nombres de columna únicos.

    El primer registro CSV se usa como fila de encabezados. La entrada no se modifica.

    Ejemplo reproducible

    name,active,score
Ada,true,42
Grace,,

        Diagnósticos
          Convierte arrays de objetos JSON a CSV
          

          Pega un documento JSON o carga un archivo local .json y elige Inspeccionar arrays. La herramienta muestra las rutas y cantidades de filas en páginas de hasta 200 arrays. Elige uno para inspeccionar la unión completa de claves de sus objetos. También se incluyen las claves que aparecen en filas posteriores:
          

          {"personas":[{"nombre":"Ada"},{"nombre":"Grace","ciudad":"Londres"}]}
          

          Reordena columnas con los botones Subir y Bajar. Un array vacío no tiene claves para inspeccionar; añade nombres de columna únicos antes de convertirlo. Elige coma, punto y coma o tabulador como delimitador, finales de registro LF o CRLF y si quieres añadir un BOM UTF-8.
          

          CSV no tiene tipos JSON. Números, booleanos, null, propiedades faltantes y cadenas vacías pueden convertirse en celdas vacías o textuales indistinguibles. Una exportación de una columna conserva explícita una última celda vacía:
          

          nombre
Ada
""
          

          Inspecciona CSV antes de elegir tipos JSON
          

          Pega texto CSV o carga un archivo local .csv; elige el delimitador y la política para campos adicionales antes de Inspeccionar CSV. Los encabezados deben ser únicos y no estar vacíos. Después de inspeccionarlos, elige un tipo para cada encabezado, incluidos los generados. No se infieren tipos: cada columna queda como cadena hasta que elijas número o booleano.
          

          Por ejemplo, 00123 permanece como la cadena "00123" de forma predeterminada. Una fila corta omite la propiedad faltante por defecto. Una fila larga falla con la política predeterminada Rechazar; Ampliar añade nombres como column_3 para los campos extra. Las celdas vacías pueden conservarse como cadenas, convertirse en null u omitirse. También puedes elegir si las filas cortas omiten o completan valores faltantes.
          

          El lector CSV admite campos entre comillas, comillas dobles escapadas, delimitadores dentro de comillas y celdas multilínea entrecomilladas. Acepta entrada LF y CRLF. Retira una firma BOM UTF-8 inicial para analizarla y muestra un aviso.
          

          Protección de fórmulas y texto exacto
          

          Por defecto, se antepone un apóstrofo al texto CSV que empieza con =, +, - o @ para reducir el riesgo de ejecución de fórmulas en hojas de cálculo. Esto puede cambiar el texto exacto. Desactiva la protección para exportar texto exacto. Si proteger encabezados los vuelve idénticos, el conversor informa HEADER_PROTECTION_COLLISION y no crea un resultado; elige texto exacto o edita los encabezados de origen y vuelve a intentar.
          

          JSON a CSV también puede advertir de pérdida de información de tipos JSON o precisión numérica. Revisa estos avisos cuando vayas a usar el CSV como datos y no solo mostrarlo en una hoja de cálculo.
          

          Límites del navegador y privacidad
          

          Los límites de 4 MiB por archivo, 1.000.000 de unidades UTF-16 de entrada, 2.000.000 de salida, 20.000 filas de datos, 200 columnas, 100.000 unidades por celda, 75.000 posiciones de celdas de datos y 20.000 unidades de vista previa mantienen acotado el procesamiento. La vista previa no es la salida completa: Copiar todo y Descargar solicitan el resultado retenido únicamente al activar su botón. Una vista truncada nunca se copia como si estuviera completa.
          

          El análisis y la conversión se ejecutan en un Web Worker local. La entrada no se envía a un servidor, no aparece en la URL ni se guarda en almacenamiento del navegador. Los errores indican rutas JSON o fila lógica, campo y línea/columna físicas de CSV cuando estén disponibles. Editar la entrada activa borra su resultado; cancelar detiene la operación del Worker sin modificar la entrada.
