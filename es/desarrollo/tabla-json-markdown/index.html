Visualiza un array JSON como tabla y exporta Markdown

Convierte un array de objetos JSON en una tabla. Elige columnas y filas, y copia o descarga el Markdown para tu documentación.

Espacio de trabajo de la herramienta

Tabla JSON / JSON a Markdown

Activa JavaScript para usar esta herramienta local.

Elige explícitamente un array de objetos. Strings y encabezados conservan comillas JSON; los saltos se muestran como escapes. ∅ indica una propiedad ausente, distinta de null y "". Objetos y arrays aparecen como JSON compacto; las columnas mantienen claves literales y orden fuente.

El documento se procesa localmente en tu navegador. No se sube, carga remotamente ni guarda la entrada.

Archivo: 4000000 bytes; entrada: 1000000 unidades UTF-16; profundidad: 200; nodos: 100000; filas: 20000; columnas descubiertas: 200; posiciones de celdas incluidas: 75000.

Filas a incluir

Texto de celda: 10000; encabezados: 20000; fila: 100000; tabla: 1000000; Markdown: 2000000 unidades UTF-16. No todos los máximos se admiten simultáneamente. Elige menos columnas o las primeras N filas para reducir la salida.

      Elige los datos de la tabla

      Pega JSON estricto o abre un archivo .json UTF-8 y pulsa Analizar arrays. Selecciona el array que quieras usar, incluido $ si el documento es un array, y pulsa Inspeccionar columnas. Todos sus elementos deben ser objetos, aunque solo vayas a exportar las primeras filas.

      La herramienta busca columnas en todo el array, incluidas las propiedades que solo aparecen al final. Selecciona al menos una y usa Mover arriba/abajo para ordenarlas. Los nombres se interpretan literalmente: un punto en una clave no indica una ruta anidada. Los objetos y arrays anidados permanecen juntos en una celda.

      Si el documento no contiene arrays, no hay datos que convertir en tabla. Un array vacío [], o uno que solo contiene objetos vacíos, no tiene columnas. Se rechazan comentarios, JSONC, JSON5 y claves duplicadas.

      Valores ausentes, null y cadenas vacías

      [{"id":"00123","name":"Ana"},{"name":"Beto","active":true}]

      Este ejemplo produce las columnas id, name y active. La primera fila contiene "00123", "Ana" y ∅; la segunda, ∅, "Beto" y true.

      Los símbolos distinguen tres casos: ∅ indica que la propiedad no existe, null es un valor nulo explícito y "" es una cadena vacía. Las cadenas y los encabezados conservan las comillas JSON. Los saltos de línea aparecen como escapes JSON y los valores anidados se muestran como JSON compacto.

      Los números conservan su escritura original, incluidos 1.0, 1e0, -0 y 9007199254740993. Un aviso de precisión no significa que se haya redondeado el texto mostrado; un número fuera del rango admitido, como 1e999, se rechaza.

      Exporta las filas que necesitas

      Elige todas las filas o las primeras N y pulsa Preparar tabla. N debe ser un entero positivo. Esa selección determina qué se exporta; cambiar de página no la modifica. Puedes ver hasta 10, 25 o 50 filas por página, y menos si las celdas contienen mucho texto.

      Pulsa Generar Markdown para crear una tabla compatible con GitHub Flavored Markdown. Los caracteres que podrían interpretarse como formato se codifican: una barra vertical pasa a &#124; y las comillas a &#34;. Así, el HTML, las imágenes o el Markdown presentes en los datos se muestran como texto. Un visor Markdown aún puede convertir las URL o los correos en enlaces.

      Copiar y descargar incluyen todas las filas seleccionadas. El archivo se llama json-table.md, usa UTF-8 sin BOM y saltos LF, incluido uno al final. Si falla el portapapeles, usa la copia manual. Revisa el resultado en el visor donde vayas a utilizarlo: los dialectos varían y la tabla no permite reconstruir el JSON original.

      Límites y procesamiento local

      Límite Máximo
      Archivo 4.000.000 bytes
      Entrada 1.000.000 unidades UTF-16
      Contenedores anidados / valores JSON 200 niveles / 100.000
      Filas de origen / columnas 20.000 / 200
      Posiciones de celda seleccionadas 75.000
      Texto por celda 10.000 unidades UTF-16
      Tabla completa / Markdown 1.000.000 / 2.000.000 unidades UTF-16

      Los encabezados largos, las filas grandes o las estructuras complejas pueden alcanzar antes otros límites de procesamiento. Si hay un error, no se recortan celdas ni se entrega una tabla parcial. Si el Markdown supera su límite, la tabla preparada sigue disponible, pero no se ofrece una exportación parcial.

      El procesamiento usa un Worker local y requiere JavaScript. La entrada y la salida no se suben ni se guardan. Los archivos deben usar UTF-8; se retira un BOM inicial con aviso y se rechaza un segundo.

      Si cambias la entrada, el array, las columnas o la selección de filas, prepara la tabla de nuevo. Cancelar conserva la entrada; al reintentar, se vuelve a analizar.
