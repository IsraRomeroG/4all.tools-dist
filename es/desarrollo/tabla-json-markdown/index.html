Visualiza un array JSON como tabla y exporta Markdown

Elige un array de objetos, selecciona columnas literales y exporta una tabla Markdown GFM segura localmente en tu navegador.

Espacio de trabajo de la herramienta

Tabla JSON / JSON a Markdown

Activa JavaScript para usar esta herramienta local.

Elige explícitamente un array de objetos. Strings y encabezados conservan comillas JSON; los saltos se muestran como escapes. ∅ indica una propiedad ausente, distinta de null y "". Objetos y arrays aparecen como JSON compacto; las columnas mantienen claves literales y orden fuente.

El documento se procesa localmente en tu navegador. No se sube, carga remotamente ni guarda la entrada.

Filas a incluir

Texto de celda: 10000; encabezados: 20000; fila: 100000; tabla: 1000000; Markdown: 2000000 unidades UTF-16. No todos los máximos se admiten simultáneamente. Elige menos columnas o las primeras N filas para reducir la salida.

      Elige el array y las columnas

      Pega JSON estricto o abre un archivo .json UTF-8 y pulsa Analizar arrays. Elige explícitamente un array fuente, también si es la raíz $, y pulsa Inspeccionar columnas. Los arrays se muestran por rutas literales y páginas. Todas las filas deben ser objetos, incluso las que después omitas. Se rechazan claves duplicadas decodificadas, JSONC, JSON5 y UTF-8 inválido. Un JSON válido sin arrays tiene estado propio; [] y arrays de objetos vacíos no tienen columnas.

      La unión de columnas abarca todas las filas en orden fuente, incluidas claves tardías. Elige un subconjunto no vacío y usa Mover arriba/abajo para ordenar la exportación. Claves vacías, numéricas, puntos, corchetes, Unicode y __proto__ son literales. [{"":null,"10":1,"2":2},{"2":3,"late":true}] descubre "", "10", "2", "late" en ese orden. Los objetos anidados son celdas; no se aplanan.

      Las mismas celdas en ambas salidas

      [{"id":"00123","name":"Ana"},{"name":"Beto","active":true}]

      Las columnas predeterminadas son id, name, active. La primera fila muestra "00123", "Ana", ∅; la segunda, ∅, "Beto", true. Strings y encabezados conservan comillas JSON. Ausencia es ∅, null es null y string vacío es "". Saltos y controles se muestran como escapes JSON. Los anidados usan JSON compacto en orden fuente. Los números conservan 1.0, 1e0, -0 y 9007199254740993, también dentro de anidados. El aviso de precisión describe la aproximación interna del parser; un desbordamiento como 1e999 se rechaza.

      Elige todas las filas o las primeras N, con N entero positivo. La omisión deliberada se anuncia por separado; la unión sigue abarcando todo el array. Preparar tabla crea el resultado elegido. Las páginas de 10/25/50 filas indican el rango real y pueden reducirse por ancho o texto. Paginar nunca cambia las filas exportadas.

      Generar, copiar y descargar Markdown

      Pulsa Generar Markdown para exportar todas las filas incluidas desde las mismas celdas preparadas. El destino es GitHub Flavored Markdown con tablas y entidades numéricas. La puntuación ASCII se codifica deliberadamente: un pipe de datos pasa a &#124; y las comillas a &#34;. La sintaxis HTML, de imágenes y Markdown se escapa conservando el texto. Un visor Markdown puede convertir URLs o correos en enlaces clicables después de decodificar las entidades. La tabla local muestra solo texto. Los escapes de saltos JSON permanecen visibles. La fuente Markdown puede ser más larga que la tabla visible. La herramienta no ejecuta un renderizador Markdown.

      Copiar entrega la salida completa; si falla el portapapeles, selecciona el campo readonly y copia manualmente. La descarga entrega el mismo texto como json-table.md, UTF-8 sin BOM, saltos LF y un LF final. Un límite por expansión Markdown conserva la tabla válida sin ofrecer exportación parcial. Markdown no es JSON reversible ni se promete compatibilidad con todos los dialectos.

      Procesamiento local y límites

      Se requieren JavaScript y un Worker local. Entrada y salida no se suben ni guardan en storage, logs o URLs. Las herramientas relacionadas abren sin transferir datos. Cambiar entrada, array, columnas o límite de filas invalida resultados; cambiar página conserva la exportación. Cancelar termina el Worker y reintentar analiza la fuente actual. Un archivo rechazado conserva el texto anterior. Se avisa el retiro de un BOM inicial; un segundo BOM inicial es inválido.

      Archivo: 4.000.000 bytes; entrada: 1.000.000 unidades UTF-16; profundidad: 200; nodos: 100.000; filas: 20.000; unión: 200 columnas; claves: 1.000 unidades; posiciones incluidas: 75.000. Texto por celda: 10.000; encabezados: 20.000; fila: 100.000; tabla: 1.000.000; Markdown: 2.000.000 unidades. Una página monta hasta 50 filas, 2.500 celdas y 200.000 unidades de texto. Parseo y trabajo estructural también tienen presupuestos duros: no todos los máximos se admiten simultáneamente. Un fallo duro no ofrece tabla parcial ni celdas recortadas. No incluye edición, filtros, ordenación de filas, esquema manual, flatten, reparación, CSV adicional, XLSX ni exportación HTML.
