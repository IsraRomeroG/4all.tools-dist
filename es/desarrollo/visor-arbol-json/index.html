Cómo funciona el visor de árbol

Pega un único valor JSON estricto completo y elige Explorar JSON. Expande objetos y arrays, carga listas grandes por páginas, selecciona una fila y copia su ruta.

La raíz puede ser cualquier valor JSON, incluso un primitivo como 42 o true. Los objetos y arrays vacíos aparecen como contenedores sin elementos.

Los nombres de propiedad sencillos usan puntos, como $.name; las posiciones de arrays usan corchetes, como $[0]; y los nombres especiales usan corchetes con comillas, como $["a.b"]. Esta ruta visible no ejecuta una consulta JSONPath.

Un número grande puede perder precisión en su valor de tipo number de JavaScript. Cuando se detecta, la vista previa conserva el lexema numérico del texto original.

Límites: 1.000.000 unidades de código UTF-16, 200 niveles de anidamiento, 100.000 valores, 100 diagnósticos, 1.000.000 unidades de trabajo del analizador, 100.000 visitas al índice del árbol, 50 elementos por página, 500 filas montadas y 120 unidades de código UTF-16 por vista previa. Tiempo máximo: 15 segundos para el análisis y 3 segundos para una página de elementos.

    Diagnósticos de entrada

      Explora un valor JSON estricto

      Pega un único valor JSON completo y elige Explorar JSON. El análisis solo empieza después de esa acción. El árbol muestra primero la raíz; expande un objeto o array para inspeccionar sus elementos. Las listas extensas se dividen en páginas de 50 filas. Los controles de página anterior y siguiente cargan elementos bajo demanda. Los objetos y arrays vacíos se identifican como contenedores sin elementos. La raíz también puede ser un valor primitivo como 42, true, null o "hola".

      Usa las flechas del teclado para moverte por el árbol. Selecciona una fila para ver el tipo, la profundidad, la vista previa y la ruta. Elige Copiar ruta seleccionada para copiar esa ruta legible. Este ejemplo incluye un array y una propiedad cuyo nombre literal contiene un punto y corchetes:

      {"name":"Ada","tags":["json","tools"],"a.b[0]":{"enabled":true}}

      El elemento del array tiene la ruta $.tags[0]. La propiedad especial tiene la ruta $["a.b[0]"], que conserva su nombre literal completo. Los nombres simples usan notación con puntos, como $.name; las posiciones de arrays usan corchetes. Esta notación identifica una ubicación para mostrarla o copiarla, pero no ejecuta una consulta JSONPath.

      JSON estricto, diagnósticos y precisión numérica

      La entrada debe ser JSON estricto: no se aceptan comentarios, comas finales, cadenas con comillas simples ni nombres de propiedad duplicados. Los errores y avisos del analizador se muestran con una ubicación del texto o una ruta JSON cuando está disponible. La lista de diagnósticos tiene un límite e indica si no se muestran todos.

      Los números JSON se analizan como valores de tipo number de JavaScript para su inspección semántica. Un entero grande o un número con muchas cifras significativas puede perder precisión en ese valor. Si el analizador detecta ese riesgo, la herramienta muestra un aviso. La vista previa del número usa el lexema original, por lo que conserva cómo estaba escrito aunque el valor representado pueda haber perdido precisión.

      Límites del navegador y de visualización

      La herramienta admite hasta 1.000.000 de unidades de código UTF-16, 200 niveles de anidamiento, 100.000 valores JSON, 100 diagnósticos y 1.000.000 unidades de trabajo de análisis. La creación del árbol permite hasta 100.000 visitas al índice. Cada página contiene como máximo 50 filas y se montan hasta 500 filas a la vez. Las vistas previas están limitadas a 120 unidades de código UTF-16. El análisis espera hasta 15 segundos por la respuesta del worker y la carga de una página de elementos espera hasta 3 segundos. Estos límites mantienen acotados el trabajo y la interfaz; contrae ramas o reduce la entrada si se alcanza un límite.

      Tu JSON se procesa localmente en este navegador. Esta herramienta no lo envía a un servidor, lo coloca en la URL ni lo guarda. Formateador y validador JSON comprueba o formatea la entrada antes de explorarla; Comparador JSON compara dos documentos cuando necesitas revisar sus diferencias.
