Convierte JSON y YAML localmente

Convierte JSON estricto a YAML o un subconjunto YAML compatible con JSON a JSON, conservando orden de miembros y escritura numérica en tu navegador.

Espacio de trabajo de la herramienta

Dirección de conversión

YAML 1.2.2, subconjunto compatible con JSON

Opciones de salida

Pega texto o elige un archivo UTF-8 local. La conversión empieza solo al pulsar Convertir.

Elige dirección e introduce texto, o inserta un ejemplo.

No hay Worker local disponible. La conversión no puede ejecutarse en este navegador.

Vista previa de solo lectura. Copiar y descargar usan la salida completa vigente.

Diagnósticos y avisos

    Se omitieron detalles o la inspección no pudo terminar. Los conteos describen la entrada inspeccionada.

    Capacidades admitidas

    Un documento; claves string; números con escritura JSON. Se omiten comentarios y formato. Tags, anchors, aliases y claves merge quedan fuera del subconjunto.

    Los valores plain yes y fechas son strings; true es booleano; una clave 1 requiere comillas; a: es null.

    Para un número YAML no admitido, usa escritura JSON compatible o comillas si deseas un string. Se conservan los lexemas numéricos; otros consumidores pueden redondear enteros grandes o decimales precisos, o convertir un número muy pequeño en cero.

    Límites

    Entrada: 1.000.000 unidades UTF-16 / 4.000.000 bytes UTF-8. Salida: 2.000.000 unidades / 8.000.000 bytes. Archivo: 4.000.000 bytes. Profundidad: 100. Valores: 100.000.

    Procesamiento local. El texto y los archivos no se suben ni se guardan.

    JSON → YAML: elige cómo escribir los strings

    Selecciona JSON → YAML, pega JSON estricto o carga un archivo .json local y pulsa Convertir. Elige indentación de 2 o 4 espacios y strings entre comillas (default) o bloques literales multilínea. La conversión no empieza automáticamente y el original permanece en el editor.

    {"code":"00123","active":true,"missing":null,"items":[1,"yes",false,null,{},[]],"message":"Hello\nWorld\n"}

    La salida default pone entre comillas todas las claves y los strings. El modo literal usa un bloque solo cuando conserva exactamente el string; en otros casos mantiene las comillas. Conserva contenedores vacíos, arrays heterogéneos, strings y orden de miembros. JSONC, JSON5, claves duplicadas, reparación y detección automática de formato quedan fuera de esta herramienta.

    YAML → JSON: resuelve los datos, no el formato

    Selecciona YAML → JSON, pega texto o carga un archivo .yaml o .yml, elige 2 o 4 espacios y pulsa Convertir. Las extensiones no distinguen mayúsculas; el MIME no determina la aceptación. Los archivos deben ser UTF-8 estricto. Se retira un BOM UTF-8 inicial con aviso; dos BOM iniciales se rechazan. Los saltos LF/CRLF/CR originales permanecen en el modelo de entrada.

    # Ejemplo local; este comentario se omite de JSON
code: "00123"
active: true
missing:
items: [1, "yes", false, null, {}, []]
message: |
  Hello
  World

    missing: es null implícito. "00123" entre comillas es un string; 00123 plain se rechaza como número fuera del perfil. yes plain y fechas como 2026-10-04 son strings; true es booleano. Una clave 1 sin comillas no es string y se rechaza: escríbela como "1".

    YAML 1.2.2, subconjunto compatible con JSON

    No es un editor YAML general. Admite un documento, mapas con claves string, arrays, strings, números finitos con gramática JSON, booleanos, null, colecciones block/flow y bloques literales/plegados. Admite una directiva %YAML 1.2 válida con su marcador de inicio. Rechaza tags explícitos, anchors, aliases, claves merge sin comillas, duplicados, claves no string, varios documentos y otras directivas. Los errores distinguen sintaxis inválida de una construcción YAML válida fuera del subconjunto.

    Números como 0x10, +1 o .inf quedan fuera del perfil numérico. Usa escritura JSON admitida cuando corresponda, o comillas si deseas un string; el conversor no repara el texto. 1_000 permanece como string según la clasificación admitida, sin coerción numérica. Se rechaza overflow no finito.

    Escritura numérica y recorridos de ida y vuelta

    Lexemas como -0, 1.0, 1e0, 9007199254740993, 0.1234567890123456789 y 1e-400 conservan su escritura. Revisa los avisos de precisión: otros consumidores pueden redondear un entero grande o decimal preciso, o convertir un valor con underflow en cero. Conservar el texto no garantiza la precisión de otro programa.

    La ida y vuelta conserva valores resueltos, strings, orden de arrays, nombres/orden literales de miembros y lexemas numéricos dentro del subconjunto. Los comentarios YAML se omiten con conteo exacto. No se reconstruyen estilo, comentarios, directivas, comillas ni disposición de bloques. Los bloques literales/plegados se resuelven primero a su valor string; después JSON escapa ese valor.

    Exportación completa, vista previa y límites locales

    Copiar y descargar exportan toda la salida vigente aunque la vista readonly muestre solo 20.000 unidades UTF-16. Tras fallo del portapapeles, una acción explícita muestra el texto completo para copia manual. Las descargas son converted.yaml (application/yaml) o converted.json (application/json), UTF-8 sin BOM y con LF final.

    Los límites son 1.000.000 unidades UTF-16 y 4.000.000 bytes UTF-8 de entrada; 2.000.000 unidades y 8.000.000 bytes de salida; un archivo de hasta 4.000.000 bytes; 250.000 unidades fuente o decodificadas por escalar/clave; 100 contenedores anidados; 100.000 valores; 300.000 tokens de sintaxis; 4.000.000 unidades de trabajo propio; 100 detalles de diagnóstico retenidos; y 10.000 ms por operación Worker. UTF-16 puede limitar antes que la cota de bytes. Todas las cotas operan juntas; las ubicaciones detalladas están acotadas y los conteos de avisos siguen visibles.

    El procesamiento usa un Worker local cancelable. No se suben texto/archivos, no se guardan en almacenamiento del navegador ni se añaden a URLs. Editar, cambiar opciones/modo, ejemplo, limpiar o seleccionar archivo invalida salida y exportación. Un límite, error, cancelación o timeout no produce salida parcial ni recupera un resultado anterior. Limpiar conserva la dirección y restaura defaults de opciones. Cancelar conserva la entrada para reintentar. Sin JavaScript o Worker local no hay conversión.
