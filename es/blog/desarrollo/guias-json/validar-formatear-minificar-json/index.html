Validar, formatear o minificar JSON: qué acción elegir

Elige entre comprobar la sintaxis, hacer el JSON más legible o generar texto compacto, y conoce qué cambia en cada caso.

Publicado: 30 de septiembre de 2026
Categorías: Guías de JSON

Valida JSON si necesitas saber si su sintaxis es correcta; formatéalo si quieres leerlo o editarlo con sangría; minifícalo si necesitas una representación compacta. La herramienta comprueba la sintaxis antes de formatear o minificar. Si la entrada es inválida, ninguna de esas dos acciones la repara.

Lo que necesitas Elige Resultado visible Ten en cuenta
Saber si la sintaxis es válida Validar Un estado o diagnóstico, sin documento nuevo No comprueba que los datos cumplan las reglas de tu aplicación.
Leer o editar la estructura Formatear JSON con saltos de línea y sangría Solo genera salida si la entrada se puede analizar.
Obtener texto compacto Minificar JSON serializado sin espacios de presentación No crea un archivo comprimido.

Puedes probar la acción que corresponda en el formateador y validador JSON. Conserva el original si vas a copiar una salida transformada.

Un documento, tres resultados distintos

Usaremos esta misma entrada válida en las tres operaciones:

{"producto":"Cuaderno", "activo":true, "etiquetas":["papel","azul"]}

Validar informa JSON válido. La validación no produce otro documento: solo confirma que el texto puede analizarse como JSON.

Formatear con una sangría de dos espacios genera una versión para leer la estructura:

{
  "producto": "Cuaderno",
  "activo": true,
  "etiquetas": [
    "papel",
    "azul"
  ]
}

Minificar genera una versión compacta en una línea:

{"producto":"Cuaderno","activo":true,"etiquetas":["papel","azul"]}

En este ejemplo, las dos transformaciones representan los mismos campos y valores analizados; cambia su presentación. La especificación de JSON permite espacios de presentación entre elementos de la sintaxis, pero quitarlos no convierte el texto en ZIP ni garantiza una mejora de rendimiento de red.

Si la entrada es inválida

{"producto":} no contiene un valor después de los dos puntos. Al validarlo, la herramienta muestra un diagnóstico de sintaxis. Al intentar formatearlo o minificarlo, tampoco obtiene un JSON de salida: primero hay que corregir la entrada y volver a comprobarla. Para localizar la causa, sigue la guía de errores de sintaxis JSON.

Antes de usar la salida

Formatear y minificar analizan y serializan de nuevo el documento. Por eso no prometen conservar el texto byte por byte: la herramienta advierte sobre claves duplicadas, cuyo último valor es el efectivo, y sobre enteros grandes que pueden perder precisión. Si estos casos afectan a tus datos, revisa la advertencia y compara la salida con el original antes de utilizarla.

Las tres acciones tratan la sintaxis. No comprueban campos obligatorios, tipos exigidos por un JSON Schema ni reglas de negocio. Si necesitas verificar esos requisitos, hazlo por separado después de confirmar que el documento es válido.
