About 4all.tools

4all.tools brings together tools for working with JSON: finding a syntax error, comparing two API responses, or converting data into a format another program can read.

Start with the task at hand

Paste a document or open a local file in the tool you need. Each JSON tool explains what it accepts, what the result means, and what may change during conversion. For example, converting JSON to XML can lose the distinction between a number and a string.

The guides work through examples you can try yourself, from fixing a missing comma to understanding why inserting an array element creates several differences.

Your documents stay in your browser

The JSON tools process documents locally. You can review a result before copying or downloading it. Each tool describes its own size limits and any caveats that matter when using its output.

Read in your language

The tools and guides are available in English, Spanish, Portuguese and French. Use the language selector to open another version of the page.

If an example is unclear or a result looks wrong, the contact page explains how to report it. Include the tool name and a small example without private data so the problem can be reproduced.
