À propos de 4all.tools

4all.tools réunit des outils pour travailler avec JSON : trouver une erreur de syntaxe, comparer deux réponses d’une API ou convertir des données dans le format attendu par un autre programme.

Partez de votre besoin

Collez un document ou ouvrez un fichier local dans l’outil choisi. Chaque outil explique les données qu’il accepte, la lecture du résultat et les changements possibles lors d’une conversion. Passer de JSON à XML peut, par exemple, faire perdre la distinction entre un nombre et une chaîne de caractères.

Les guides proposent des exemples à essayer, de la correction d’une virgule manquante à l’explication des différences provoquées par l’insertion d’un élément dans un tableau.

Vos documents restent dans le navigateur

Les outils JSON traitent les documents localement. Vous pouvez vérifier le résultat avant de le copier ou de le télécharger. Chaque outil précise ses limites de taille et les précautions utiles pour exploiter sa sortie.

Choisissez votre langue

Les outils et les guides sont disponibles en français, anglais, espagnol et portugais. Le sélecteur de langue permet d’ouvrir une autre version de la page.

Si un exemple manque de clarté ou si un résultat semble incorrect, consultez la page de contact. Indiquez l’outil et un petit exemple sans données privées pour permettre de reproduire le problème.
