Outils pour Développeurs

Utilitaires destinés aux développeurs qui travaillent avec des formats de données, des encodeurs, des générateurs et des technologies web.

Explorez des outils pour développeurs organisés pour des flux de travail rapides et ciblés.

Outils

  • Analyseur de taille JSON

    Mesurez la taille du JSON en octets UTF-8, comparez le gain de minification et examinez ses valeurs, tableaux et profondeur.

  • Aplatir / Reconstruire JSON

    Transformez un JSON imbriqué en chemins et valeurs, ou reconstruisez sa structure à partir de ces chemins, dans votre navigateur.

  • Comparateur JSON

    Comparez deux documents JSON stricts selon leurs valeurs. Consultez les ajouts, suppressions et modifications avec des diagnostics localisés et des aperçus limités.

  • Convertisseur JSON / SQL

    Convertissez des lignes JSON plates vers un sous-ensemble SQL documenté de PostgreSQL ou SQLite, ou importez CREATE TABLE et INSERT admis en JSON.

  • Convertisseur JSON ↔ XML

    Convertissez JSON en XML ou XML en JSON dans votre navigateur. Utilisez attributs et éléments répétés, et vérifiez les changements.

  • Convertisseur JSON ↔ YAML

    Convertissez du JSON strict en YAML ou un sous-ensemble YAML compatible avec JSON en JSON, en conservant l’ordre des membres et l’écriture numérique dans le navigateur.

  • Convertisseur JSON vers CSV

    Convertissez des tableaux d’objets JSON en CSV ou inspectez les en-têtes CSV et transformez les lignes en JSON avec des choix explicites de types et de lignes irrégulières.

  • Explorateur d’arbre JSON

    Explorez du JSON strict dans un arbre extensible et limité. Inspectez les types, parcourez les grands tableaux par pages et copiez un chemin JSON dans votre navigateur.

  • Formateur et Validateur JSON

    Formatez, embellissez et validez du JSON en ligne. Détectez les erreurs de syntaxe et rendez les données JSON plus lisibles.

  • Générateur de JSON Schema

    Générez un JSON Schema à partir de vos exemples. Vérifiez les champs obligatoires, contrôlez les exemples et téléchargez le schéma.

  • JSON vers C#

    Inférez localement des classes C# avec clés JSON exactes, présence JsonRequired et capacités explicites des annotations nullable et nombres raw.

  • JSON vers Go

    Inférez localement structs et maps raw Go, conservez les lexèmes numériques avec json.Number et comprenez les pointeurs facultatifs.

  • JSON vers Python

    Inférez des déclarations TypedDict localement, préservez les clés exactes et distinguez les champs absents de None.

  • JSON vers TypeScript

    Inférez des types TypeScript depuis des documents JSON complets, préservez les clés littérales et distinguez absence et null localement.

  • Recherche dans JSON

    Trouvez du texte littéral dans les clés et valeurs primitives de JSON strict, copiez le chemin ou localisez la valeur originale dans votre navigateur.

  • Recherche JSONPath

    Recherchez dans un document JSON strict avec une requête JSONPath prise en charge, consultez les chemins et aperçus, puis copiez un chemin ou une valeur dans le navigateur.

  • Réparer JSON

    Convertissez les commentaires et virgules finales JSONC en JSON strict, ou tentez une réparation heuristique limitée et vérifiez chaque changement.

  • Tableau JSON / JSON vers Markdown

    Présentez un tableau d’objets JSON sous forme de table. Choisissez les colonnes et les lignes, puis exportez le Markdown.

  • Trier les clés JSON

    Triez les clés JSON strictes dans l’ordre croissant ou décroissant, récursivement ou à la racine, en conservant tableaux et tokens numériques originaux localement.

  • Validateur JSON Schema

    Vérifiez un document JSON strict avec un sous-ensemble local et limité de JSON Schema draft-07.
