Formateur et Validateur JSON Gratuit en Ligne

Formatez, embellissez et validez du JSON en ligne. Détectez les erreurs de syntaxe et rendez les données JSON plus lisibles.

Espace de travail de l’outil

Cet outil nécessite JavaScript pour fonctionner dans votre navigateur.

Validez, formatez ou minifiez du JSON strict localement dans votre navigateur. Le parseur applique des limites de sécurité explicites ; vous pouvez aussi charger des fichiers JSON jusqu’à 5 MiB.

Conseils et limites du JSON
  • Les propriétés dupliquées produisent un avertissement ; la dernière valeur est effective.
  • Les grands entiers peuvent perdre en précision, car les nombres JSON utilisent les valeurs numériques JavaScript.
  • Les limites d’entrée, d’imbrication, de nœuds, de traitement, de sortie et de taille de fichier protègent le navigateur. Les limites de texte utilisent des unités UTF-16 ; celles des fichiers utilisent des octets.
  • Les signatures BOM UTF-8 sont refusées. Le texte collé est conservé exactement comme saisi, sans être coupé ni normalisé.

Les opérations JSON sont traitées localement dans votre navigateur et ne sont pas envoyées à un serveur pendant l’utilisation.

Formateur JSON

Un formateur JSON ajoute une indentation et des retours à la ligne sans modifier la structure analysée. « Embellir », prettify et pretty print désignent la même opération. Choisissez 2 espaces, 4 espaces ou des tabulations, puis utilisez Formater et valider le JSON pour contrôler la syntaxe et créer un résultat lisible.

Voici un JSON valide que le formateur peut indenter :

{
  "name": "4all.tools",
  "active": true,
  "score": 42,
  "notes": null,
  "archived": false
}

Validateur JSON

Le validateur contrôle la syntaxe JSON standard. Il détecte notamment les virgules manquantes ou finales, les chaînes entre apostrophes, les commentaires, les propriétés sans guillemets et les accolades ou crochets non fermés. Lorsque le navigateur fournit une position exploitable, le diagnostic inclut la ligne, la colonne et le contexte voisin.

Cet exemple est invalide, car il manque une virgule après la première propriété :

{
  "name": "4all.tools"
  "active": true
}

Valider la syntaxe ne revient pas à valider avec JSON Schema. Valider le JSON vérifie que le texte peut être analysé comme du JSON standard ; cette action n’applique ni propriétés obligatoires, ni types de données, ni autres règles d’un schéma, et ne répare pas automatiquement la saisie.

Comment formater du JSON en ligne

  1. Collez du JSON dans Entrée ou chargez un fichier .json autorisé.
  2. Choisissez une indentation de 2 espaces, 4 espaces ou tabulations.
  3. Sélectionnez Formater et valider le JSON.
  4. Consultez Résultat. Une saisie valide produit du JSON formaté ; si elle est invalide, elle reste dans Entrée et un diagnostic indique l’emplacement lorsqu’il est disponible.
  5. Copiez Résultat ou téléchargez le fichier JSON formaté actuel.

Comment valider du JSON en ligne

  1. Collez ou chargez le JSON à contrôler.
  2. Sélectionnez Valider le JSON sans devoir le formater.
  3. Recherchez l’état JSON valide ou consultez le diagnostic de syntaxe.
  4. Si une ligne, une colonne et du contexte sont disponibles, utilisez-les pour corriger Entrée, puis validez à nouveau.

Minificateur JSON

Minifier le JSON analyse une saisie valide et la sérialise sous forme de JSON compact sur une seule ligne. La minification supprime les espaces de mise en forme ; elle ne compresse pas le fichier et ne crée ni ZIP ni autre archive. Le résultat actuel peut être copié ou téléchargé.

Traitement local dans le navigateur

Le formatage, la validation, la minification, la lecture de fichiers, la copie et la préparation du téléchargement s’effectuent localement dans le navigateur. Pendant ces opérations, le JSON n’est pas envoyé à un serveur applicatif et n’est pas stocké à distance par cet outil.

Questions fréquentes

Pourquoi l’erreur apparaît-elle après la virgule manquante ?

La position indique l’endroit où l’analyseur n’a plus pu continuer. Si la ligne signalée semble correcte, vérifiez la fin de la propriété précédente. Dans l’exemple invalide ci-dessus, la virgule doit se trouver après "4all.tools".

Puis-je ouvrir un fichier .json ?

Oui. Sélectionnez ou déposez un fichier .json dans l’outil. Son texte apparaît dans l’éditeur pour vous permettre de le vérifier avant de lancer une action.

Une syntaxe valide garantit-elle des données correctes ?

Non. Par exemple, {"age":"vingt"} est du JSON valide, mais une application attendant un âge numérique peut le refuser. Utilisez un validateur JSON Schema pour vérifier des champs obligatoires, des types ou d’autres règles sur les données.

Limites de l’analyse JSON

Les clés dupliquées produisent un avertissement ; le formatage et la minification conservent la dernière valeur. Par exemple, {"nom":"Ana","nom":"Beto"} devient {"nom":"Beto"}. La validation affiche l’avertissement sans réécrire l’entrée. Supprimez les doublons involontaires avant d’utiliser le résultat.

Les très grands entiers et les décimaux de haute précision peuvent perdre en exactitude lorsqu’ils sont représentés par des nombres JavaScript. Le formatage et la minification modifient aussi les espaces et peuvent changer l’écriture des nombres ou des échappements. Conservez l’original si ces détails comptent pour votre usage.

Le texte collé est limité à 5 242 880 unités UTF-16. Un document profond ou complexe peut atteindre les limites de traitement ou de sortie plus tôt. L’entrée vide, un BOM UTF-8 initial et les nombres hors de la plage acceptée sont refusés. JSON5, commentaires, virgules finales, chaînes entre apostrophes, NaN, Infinity et undefined ne sont pas acceptés comme JSON standard. Les échappements de substituts isolés sont acceptés avec un avertissement.

Une opération annulée ou un téléchargement échoué ne signifie pas, à lui seul, que le JSON est invalide. Lisez le message précis avant de modifier le document.
