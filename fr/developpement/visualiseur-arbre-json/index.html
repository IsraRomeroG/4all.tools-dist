Explorer le JSON en ligne sous forme d’arbre

Explorez du JSON strict dans un arbre extensible et limité. Inspectez les types, parcourez les grands tableaux par pages et copiez un chemin JSON dans votre navigateur.

Espace de travail de l’outil

Explorer le JSON sous forme d’arbre

JavaScript est nécessaire pour explorer le JSON dans votre navigateur.

Saisissez une valeur JSON complète. Le traitement reste dans ce navigateur.

Entrée maximale : 1 000 000 unités de code UTF-16.

0 sur 1 000 000 unités de code UTF-16

Exemple avec un tableau et un nom de propriété spécial

{"name":"Ada","tags":["json","tools"],"a.b[0]":{"enabled":true}}

Votre JSON est traité localement et n’est ni envoyé à un serveur ni enregistré par cet outil.

Fonctionnement de l’explorateur d’arbre

Collez une valeur JSON stricte complète, puis choisissez Explorer le JSON. Développez les objets et tableaux, chargez les longues listes par page, sélectionnez une ligne et copiez son chemin.

La racine peut être toute valeur JSON, y compris une primitive comme 42 ou true. Les objets et tableaux vides apparaissent comme des conteneurs sans élément enfant.

Les noms de propriété simples utilisent un point, comme $.name ; les positions du tableau utilisent des crochets, comme $[0] ; les noms spéciaux utilisent des crochets entre guillemets, comme $["a.b"]. Ce chemin affiché ne lance pas de requête JSONPath.

Un grand nombre peut perdre en précision dans sa valeur number JavaScript. Lorsque ce risque est détecté, l’aperçu conserve le lexème numérique du texte source.

Limites : 1 000 000 unités de code UTF-16, 200 niveaux imbriqués, 100 000 valeurs, 100 diagnostics, 1 000 000 unités de travail d’analyse, 100 000 visites de l’index de l’arbre, 50 éléments par page, 500 lignes montées et 120 unités de code UTF-16 par aperçu. Délais : 15 secondes pour l’analyse et 3 secondes pour une page d’éléments.

Actions de l’arbre

Saisissez du JSON pour commencer. L’analyse débute uniquement après avoir choisi Explorer le JSON.

    Diagnostics de l’entrée

      Explorer une valeur JSON stricte

      Collez une valeur JSON complète et choisissez Explorer le JSON. L’analyse commence uniquement après cette action. L’arbre affiche d’abord la racine ; développez un objet ou un tableau pour examiner ses éléments. Les longues listes sont réparties en pages de 50 lignes. Les commandes page précédente et suivante chargent les éléments à la demande. Les objets et tableaux vides sont signalés comme des conteneurs sans élément. La racine peut aussi être une valeur primitive comme 42, true, null ou "bonjour".

      Utilisez les flèches du clavier pour parcourir l’arbre. Sélectionnez une ligne pour voir son type, sa profondeur, son aperçu et son chemin. Choisissez Copier le chemin sélectionné pour copier ce chemin lisible. Cet exemple contient un tableau et une propriété dont le nom littéral inclut un point et des crochets :

      {"name":"Ada","tags":["json","tools"],"a.b[0]":{"enabled":true}}

      L’élément du tableau a pour chemin $.tags[0]. La propriété spéciale a pour chemin $["a.b[0]"], ce qui conserve son nom littéral entier. Les noms simples utilisent la notation avec un point, comme $.name ; les positions du tableau utilisent des crochets. Cette notation sert à afficher et copier un emplacement, elle n’exécute pas une requête JSONPath.

      JSON strict, diagnostics et précision numérique

      L’entrée doit respecter JSON strict : les commentaires, virgules finales, chaînes entre apostrophes et noms de propriété dupliqués sont refusés. Les erreurs et avertissements de l’analyseur indiquent un emplacement dans le texte ou un chemin JSON lorsque ces informations sont disponibles. La liste de diagnostics est limitée et signale si certains éléments ne sont pas affichés.

      Les nombres JSON sont analysés comme des valeurs de type number JavaScript pour l’inspection sémantique. Un entier élevé ou un nombre comportant beaucoup de chiffres significatifs peut perdre en précision dans cette valeur. L’outil affiche un avertissement lorsque l’analyseur détecte ce risque. L’aperçu du nombre utilise le lexème source d’origine ; il conserve donc son écriture même si la valeur représentée a pu perdre en précision.

      Limites du navigateur et de l’affichage

      L’outil accepte jusqu’à 1 000 000 unités de code UTF-16, 200 niveaux d’imbrication, 100 000 valeurs JSON, 100 diagnostics et 1 000 000 unités de travail d’analyse. La création de l’arbre autorise aussi jusqu’à 100 000 visites de l’index. Chaque page contient au maximum 50 lignes et 500 lignes peuvent être montées à la fois. Les aperçus sont limités à 120 unités de code UTF-16. L’analyse attend jusqu’à 15 secondes la réponse du worker et une page d’éléments enfants jusqu’à 3 secondes. Ces limites bornent le travail et l’interface ; réduisez une branche ou l’entrée si une limite est atteinte.

      Votre JSON est traité localement dans ce navigateur. Cet outil ne l’envoie pas à un serveur, ne le place pas dans l’URL et ne l’enregistre pas. Formateur et validateur JSON vérifie ou formate l’entrée avant l’exploration ; Comparateur JSON compare deux documents lorsque vous voulez examiner leurs différences.

      Outils associés

      • Formateur et Validateur JSON

        Formatez, embellissez et validez du JSON en ligne. Détectez les erreurs de syntaxe et rendez les données JSON plus lisibles.

      • Comparateur JSON

        Comparez deux documents JSON stricts selon leurs valeurs. Consultez les ajouts, suppressions et modifications avec des diagnostics localisés et des aperçus limités.
