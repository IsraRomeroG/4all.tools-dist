Outils en ligne utiles pour le travail quotidien.

Outils disponibles

  • Comparateur JSON

    Comparez deux documents JSON stricts selon leurs valeurs. Consultez les ajouts, suppressions et modifications avec des diagnostics localisés et des aperçus limités.

  • Convertisseur JSON vers CSV

    Convertissez des tableaux d’objets JSON en CSV ou inspectez les en-têtes CSV et transformez les lignes en JSON avec des choix explicites de types et de lignes irrégulières.

  • Explorateur d’arbre JSON

    Explorez du JSON strict dans un arbre extensible et limité. Inspectez les types, parcourez les grands tableaux par pages et copiez un chemin JSON dans votre navigateur.

  • Formateur et Validateur JSON

    Formatez, embellissez et validez du JSON en ligne. Détectez les erreurs de syntaxe et rendez les données JSON plus lisibles.

  • Recherche JSONPath

    Recherchez dans un document JSON strict avec une requête JSONPath prise en charge, consultez les chemins et aperçus, puis copiez un chemin ou une valeur dans le navigateur.

  • Réparer JSON

    Convertissez les commentaires et virgules finales JSONC en JSON strict, ou tentez une réparation heuristique limitée et vérifiez chaque changement.

  • Validateur JSON Schema

    Vérifiez un document JSON strict avec un sous-ensemble local et limité de JSON Schema draft-07.
