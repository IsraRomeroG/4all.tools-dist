O que é JSON? Guia prático da sintaxe JSON

Entenda o que é JSON, como sua sintaxe funciona e por que ele é usado para trocar dados estruturados.

Publicado: 21 de julho de 2026
Categorias: Guias de JSON

JSON é um formato de texto usado para trocar dados estruturados. Um objeto reúne valores nomeados, enquanto um array mantém uma lista em ordem.

Valores e estrutura

JSON aceita strings, números, valores booleanos, null, objetos e arrays. Este é um exemplo válido:

{
  "name": "4all.tools",
  "active": true,
  "tags": ["json", "ferramentas"]
}

JSON tem relação com JavaScript, mas não é código JavaScript. Ele é uma notação de dados com uma sintaxe limitada que pode ser lida por muitas linguagens.

Erros comuns

Nomes de propriedades e textos precisam de aspas duplas. O JSON padrão não permite comentários nem vírgulas finais. Uma vírgula ausente, uma vírgula extra ou uma chave sem fechamento torna o documento inválido.

APIs usam JSON com frequência em requisições e respostas, e arquivos de configuração também se beneficiam de um formato legível por pessoas e fácil de analisar por programas. Use o Formatador e Validador JSON para encontrar erros de sintaxe antes de enviar um documento para uma API.

Resumo

JSON oferece uma forma portátil de trocar valores estruturados. Aprenda suas regras simples e valide os exemplos enquanto trabalha.
