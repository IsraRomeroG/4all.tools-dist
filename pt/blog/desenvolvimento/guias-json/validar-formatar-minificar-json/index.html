Validar, formatar ou minificar JSON: qual ação escolher?

Escolha entre conferir a sintaxe, facilitar a leitura do JSON e gerar texto compacto, sabendo o que muda em cada ação.

Publicado: 30 de setembro de 20262 min de leitura

Valide JSON quando precisar conferir a sintaxe; formate para ler ou editar com recuo; minifique quando precisar de uma representação compacta. A ferramenta confere a sintaxe antes de formatar ou minificar. Se a entrada for inválida, nenhuma dessas ações a corrige.

Seu objetivo Escolha Resultado visível Atenção
Saber se a sintaxe é válida Validar Um status ou diagnóstico, sem novo documento Isso não verifica as regras de dados da sua aplicação.
Ler ou editar a estrutura Formatar JSON com quebras de linha e recuo Só há saída se a entrada puder ser analisada.
Obter texto compacto Minificar JSON serializado sem espaços de apresentação Isso não cria um arquivo comprimido.

Experimente a ação escolhida no formatador e validador JSON. Guarde o original se for copiar uma saída transformada.

Um documento, três resultados diferentes

Use esta mesma entrada válida nas três ações:

{"produto":"Caderno", "ativo":true, "etiquetas":["papel","azul"]}

Validar informa JSON válido. A validação não cria outro documento: apenas confirma que o texto pode ser analisado como JSON.

Formatar com recuo de dois espaços gera uma versão mais fácil de ler:

{
  "produto": "Caderno",
  "ativo": true,
  "etiquetas": [
    "papel",
    "azul"
  ]
}

Minificar gera texto compacto em uma linha:

{"produto":"Caderno","ativo":true,"etiquetas":["papel","azul"]}

Neste exemplo, as duas transformações representam os mesmos campos e valores analisados; a apresentação muda. A especificação JSON permite espaços de apresentação entre elementos da sintaxe. Removê-los não cria um arquivo ZIP nem garante melhor desempenho da rede.

Se a entrada for inválida

{"produto":} não tem valor depois dos dois-pontos. A validação informa um problema de sintaxe. A formatação e a minificação também não conseguem gerar uma saída JSON: primeiro corrija a entrada e confira novamente. Para localizar a causa, consulte o guia sobre erros de sintaxe JSON.

Antes de usar o resultado

Formatar e minificar analisam e serializam o documento novamente. Por isso, não prometem preservar o texto byte a byte: a ferramenta avisa sobre chaves duplicadas, em que prevalece o último valor, e inteiros grandes que podem perder precisão. Se esses casos afetarem seus dados, confira o aviso e compare a saída com o original antes de usá-la.

As três ações tratam da sintaxe. Elas não verificam campos obrigatórios, tipos definidos por um JSON Schema nem regras de negócio. Confira esses requisitos separadamente após confirmar que o documento é válido.
