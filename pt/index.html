Ferramentas online úteis para o trabalho diário.

Ferramentas disponíveis

  • Achatar / Reconstruir JSON

    Transforme JSON aninhado em um mapa de caminhos e valores ou reconstrua a estrutura a partir do mapa. Processe arquivos no navegador.

  • Analisador de tamanho JSON

    Meça o tamanho do JSON em bytes UTF-8, compare a economia da minificação e examine valores, arrays e profundidade.

  • Buscar em JSON

    Encontre texto literal em chaves e valores primitivos de JSON estrito, copie o caminho ou localize o valor original no navegador.

  • Comparador de JSON

    Compare dois documentos JSON estritos pelos valores. Confira adições, remoções e alterações com diagnósticos localizados e pré-visualizações limitadas.

  • Conversor de JSON para CSV

    Converta matrizes de objetos JSON para CSV ou inspecione cabeçalhos CSV e transforme linhas em JSON com opções explícitas de tipos e linhas irregulares.

  • Conversor JSON / SQL

    Converta linhas JSON planas para um subconjunto SQL documentado de PostgreSQL ou SQLite, ou importe CREATE TABLE e INSERT aceitos como JSON.

  • Conversor JSON ↔ XML

    Converta JSON para XML ou XML para JSON no navegador. Trabalhe com atributos e elementos repetidos e confira o que muda na conversão.

  • Conversor JSON ↔ YAML

    Converta JSON estrito em YAML ou um subconjunto YAML compatível com JSON em JSON, preservando a ordem dos membros e a escrita numérica no navegador.

  • Formatador e Validador JSON

    Formate, embeleze e valide JSON online. Detecte erros de sintaxe e torne os dados JSON mais fáceis de ler.

  • Gerador de JSON Schema

    Gere um JSON Schema a partir dos seus exemplos. Revise os campos obrigatórios, verifique as amostras e baixe o esquema.

  • JSON para C#

    Infira classes C# localmente com chaves JSON exatas, presença com JsonRequired e capacidades explícitas de nullable e números raw.

  • JSON para Go

    Infira structs e mapas raw Go localmente, preserve lexemas numéricos com json.Number e entenda os ponteiros opcionais.

  • JSON para Python

    Infira declarações TypedDict localmente, preserve as chaves exatas e diferencie campos ausentes de None.

  • JSON para TypeScript

    Infira tipos TypeScript de documentos JSON completos, preserve chaves literais e diferencie campos ausentes de null localmente.

  • Localizador JSONPath

    Pesquise um documento JSON estrito com uma consulta JSONPath aceita, confira caminhos e prévias e copie um caminho ou valor no navegador.

  • Ordenar chaves JSON

    Ordene chaves de JSON estrito em ordem crescente ou decrescente, recursivamente ou na raiz, preservando arrays e tokens numéricos originais localmente.

  • Reparar JSON

    Converta comentários e vírgulas finais de JSONC em JSON estrito ou tente reparar erros comuns com heurísticas limitadas e mudanças revisáveis.

  • Tabela JSON / JSON para Markdown

    Transforme um array de objetos JSON em tabela. Escolha colunas e linhas e copie ou baixe o Markdown para sua documentação.

  • Validador de JSON Schema

    Verifique um documento JSON estrito com um subconjunto local e limitado de JSON Schema draft-07.

  • Visualizador de árvore JSON

    Explore JSON estrito em uma árvore expansível e limitada. Inspecione tipos, navegue por matrizes grandes em páginas e copie um caminho JSON sem sair do navegador.
