Pesquise um documento JSON estrito com uma consulta JSONPath aceita, confira caminhos e prévias e copie um caminho ou valor no navegador.

Encontre valores com uma consulta JSONPath

É necessário JavaScript para pesquisar JSON neste navegador.

Cole um único valor JSON estrito e completo. Objetos e arrays vazios são válidos.

Tamanho máximo do JSON: 1.000.000 unidades de código UTF-16.

0 / 1.000.000 unidades de código UTF-16

Digite uma consulta JSONPath aceita. A pesquisa começa somente quando você escolhe Buscar.

Tamanho máximo da consulta: 512 unidades de código UTF-16.

0 / 512 unidades de código UTF-16

Seu JSON e sua consulta permanecem neste navegador. Eles não são enviados a um servidor nem salvos.

Como usar este localizador

Cole o JSON e digite uma consulta; depois, escolha Buscar. A edição de qualquer campo remove os resultados anteriores. Você pode carregar o exemplo local quando quiser.

A versão 1 aceita a raiz ($), propriedades simples com ponto, propriedades entre colchetes e aspas duplas, índices de array não negativos, curingas (*) e descida recursiva básica (..propriedade ou ..*). Filtros, fatias (slices), uniões, índices negativos e propriedades entre aspas simples não são aceitos.

Escolha um resultado para ver o caminho completo e as opções de cópia. Os arrays são percorridos em ordem crescente de índice; as propriedades dos objetos seguem a ordem do arquivo de entrada. Essa ordem é um comportamento deste localizador, não uma regra universal do JSONPath.

Limites: 1.000.000 unidades UTF-16 de JSON, 200 níveis de aninhamento, 100.000 valores JSON, 100 diagnósticos, 1.000.000 unidades de trabalho do analisador, 512 unidades UTF-16 de consulta, 32 etapas de consulta, 500.000 unidades de trabalho da consulta, 200 correspondências visíveis, 1.000.000 unidades de texto nos resultados e 200.000 unidades por valor copiado. Cada operação é interrompida após 15 segundos. Se houver mais de 200 correspondências, o total não é calculado.

{"users":[{"name":"Ana"},{"name":"Beto"}],"a.b":null}

      Encontre valores em um documento JSON

      Cole um único valor JSON estrito e completo e digite uma consulta. A pesquisa só começa quando você escolhe Buscar. A edição de qualquer campo limpa os resultados exibidos; escolha Cancelar para interromper uma pesquisa sem alterar os campos. O exemplo local carrega o mesmo documento e a mesma consulta mostrados aqui:

      {"users":[{"name":"Ana"},{"name":"Beto"}],"a.b":null}

      A consulta $.users[*].name retorna primeiro $.users[0].name, com a prévia "Ana", e depois $.users[1].name, com a prévia "Beto". A consulta $.missing é válida e não encontra correspondências. A consulta raiz $ seleciona o documento inteiro, incluindo um objeto {} ou array [] vazio.

      Sintaxe JSONPath aceita

      A versão 1 aceita a raiz $, propriedades simples com ponto, como $.users, propriedades entre colchetes e aspas duplas, como $["a.b"], índices de array não negativos, como $.users[0], o curinga de filhos * e descida recursiva básica, como $..name e $..*. Filtros, fatias (slices), uniões, índices negativos e nomes de propriedade entre aspas simples não são aceitos.

      Os resultados seguem a ordem definida por este localizador: os índices dos arrays crescem a partir de zero e as propriedades dos objetos seguem a ordem do arquivo de entrada. A ordem das propriedades não é uma garantia universal do JSONPath. Cada resultado mostra o caminho completo, o tipo do valor e uma prévia de texto limitada. Escolha um resultado para ver o caminho completo e as ações Copiar caminho e Copiar valor JSON. Um aviso de possível perda de precisão permanece visível antes da cópia quando o analisador detecta esse risco.

      Limites de resultados e do navegador

      O localizador mostra no máximo 200 correspondências. Se encontrar a 201ª, ele para e informa que há mais; não calcula nem declara um total. Quando uma consulta excede o orçamento de trabalho, ela falha sem resultados parciais. Copiar um valor JSON é uma solicitação separada ao Worker, limitada a 200.000 unidades de código UTF-16. Um valor acima desse limite não é copiado e a seleção é mantida. A interface também mostra os limites de entrada, consulta, análise, resultados e tempo.

      Seu JSON e sua consulta são processados neste navegador. Eles não são colocados na URL, salvos no armazenamento do navegador nem enviados a um servidor. Formatador e validador JSON pode verificar ou formatar a entrada antes; Comparador JSON compara dois documentos para revisar as diferenças.
