Explore JSON online como uma árvore

Explore JSON estrito em uma árvore expansível e limitada. Inspecione tipos, navegue por matrizes grandes em páginas e copie um caminho JSON sem sair do navegador.

Espaço de trabalho da ferramenta

Explore JSON como uma árvore

É necessário JavaScript para explorar JSON no seu navegador.

Insira um único valor JSON completo. O processamento ocorre neste navegador.

Entrada máxima: 1.000.000 unidades de código UTF-16.

0 de 1.000.000 unidades de código UTF-16

Exemplo com uma matriz e um nome de propriedade especial

{"name":"Ada","tags":["json","tools"],"a.b[0]":{"enabled":true}}

Seu JSON é processado localmente e não é enviado a um servidor nem salvo por esta ferramenta.

Como funciona o visualizador de árvore

Cole um único valor JSON estrito completo e escolha Explorar JSON. Expanda objetos e matrizes, carregue listas grandes por página, selecione uma linha e copie seu caminho.

A raiz pode ser qualquer valor JSON, inclusive um primitivo como 42 ou true. Objetos e matrizes vazios aparecem como contêineres sem itens filhos.

Nomes simples de propriedades usam ponto, como $.name; posições da matriz usam colchetes, como $[0]; e nomes especiais usam colchetes com aspas, como $["a.b"]. Esse caminho de exibição não executa uma consulta JSONPath.

Um número grande pode perder precisão em seu valor number de JavaScript. Quando detectada, a prévia ainda usa o lexema numérico do texto original.

Limites: 1.000.000 unidades de código UTF-16, 200 níveis de aninhamento, 100.000 valores, 100 diagnósticos, 1.000.000 unidades de trabalho do analisador, 100.000 visitas ao índice da árvore, 50 itens por página, 500 linhas montadas e 120 unidades de código UTF-16 por prévia. Tempo limite: 15 segundos para análise e 3 segundos para uma página de itens.

    Diagnósticos da entrada

      Explore um valor JSON estrito

      Cole um único valor JSON completo e escolha Explorar JSON. A análise só começa depois dessa ação. A árvore mostra primeiro a raiz; expanda um objeto ou matriz para inspecionar os itens. Listas grandes são divididas em páginas de 50 linhas. Os controles de página anterior e próxima carregam itens sob demanda. Objetos e matrizes vazios são identificados como contêineres sem itens. A raiz também pode ser um valor primitivo como 42, true, null ou "olá".

      Use as setas do teclado para navegar pela árvore. Selecione uma linha para ver o tipo, a profundidade, a prévia e o caminho. Escolha Copiar caminho selecionado para copiar o caminho legível. Este exemplo contém uma matriz e uma propriedade cujo nome literal inclui ponto e colchetes:

      {"name":"Ada","tags":["json","tools"],"a.b[0]":{"enabled":true}}

      O item da matriz tem o caminho $.tags[0]. A propriedade especial tem o caminho $["a.b[0]"], que preserva o nome literal completo. Nomes simples usam notação de ponto, como $.name; posições da matriz usam colchetes. Essa notação identifica um local para exibição e cópia, mas não executa uma consulta JSONPath.

      JSON estrito, diagnósticos e precisão numérica

      A entrada deve ser JSON estrito: comentários, vírgulas finais, strings com aspas simples e nomes de propriedade duplicados não são aceitos. Erros e avisos do analisador aparecem com uma posição no texto ou um caminho JSON quando disponível. A lista de diagnósticos é limitada e informa quando nem todos são exibidos.

      Os números JSON são analisados como valores do tipo number de JavaScript para inspeção semântica. Um inteiro grande ou um número com muitos algarismos significativos pode perder precisão nesse valor. Quando o analisador detecta esse risco, a ferramenta mostra um aviso. A prévia numérica usa o lexema da fonte original, preservando a escrita do número mesmo que o valor representado possa ter perdido precisão.

      Limites do navegador e da exibição

      A ferramenta aceita até 1.000.000 unidades de código UTF-16, 200 níveis de aninhamento, 100.000 valores JSON, 100 diagnósticos e 1.000.000 unidades de trabalho de análise. A criação da árvore permite até 100.000 visitas ao índice. Cada página contém no máximo 50 linhas e até 500 linhas ficam montadas ao mesmo tempo. As prévias têm limite de 120 unidades de código UTF-16. A análise aguarda até 15 segundos pela resposta do worker, e uma página de itens filhos aguarda até 3 segundos. Esses limites mantêm o trabalho e a interface controlados; recolha ramos ou reduza a entrada se um limite for atingido.

      Seu JSON é processado localmente neste navegador. Esta ferramenta não o envia a um servidor, inclui na URL nem salva. Formatador e validador JSON verifica ou formata a entrada antes da exploração; Comparador JSON compara dois documentos quando você precisa revisar alterações entre eles.
