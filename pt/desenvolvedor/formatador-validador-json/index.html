Orientações e limites do JSON
  • Propriedades duplicadas geram um aviso; o último valor é efetivo.
  • Inteiros grandes podem perder precisão porque números JSON usam valores numéricos do JavaScript.
  • Limites de entrada, aninhamento, nós, processamento, saída e tamanho de arquivo protegem o navegador. Limites de texto usam unidades UTF-16; limites de arquivo usam bytes.
  • Assinaturas BOM UTF-8 são rejeitadas. O texto colado é mantido exatamente como inserido, sem cortes ou normalização.

As operações JSON são processadas localmente no navegador e não são enviadas a um servidor durante o uso.

Formatador JSON

Um formatador JSON adiciona recuo e quebras de linha sem alterar a estrutura analisada. “Embelezar”, prettify e pretty print descrevem a mesma operação. Escolha 2 espaços, 4 espaços ou tabulações e use Formatar e validar JSON para verificar a sintaxe e criar um resultado legível.

Este é um JSON válido que pode ser formatado:

{
  "name": "4all.tools",
  "active": true,
  "score": 42,
  "notes": null,
  "archived": false
}

Validador JSON

O validador verifica a sintaxe JSON padrão. Ele identifica erros como vírgulas finais ou ausentes, strings entre aspas simples, comentários, propriedades sem aspas e chaves ou colchetes sem fechamento. Quando o navegador fornece uma posição útil, o diagnóstico inclui linha, coluna e contexto próximo.

Este exemplo é inválido porque falta uma vírgula após a primeira propriedade:

{
  "name": "4all.tools"
  "active": true
}

Validar a sintaxe não é o mesmo que validar com JSON Schema. Validar JSON verifica se o texto pode ser analisado como JSON padrão; não aplica propriedades obrigatórias, tipos de dados ou outras regras de um esquema e não corrige a entrada automaticamente.

Como formatar JSON online

  1. Cole o JSON em Entrada ou carregue um arquivo .json permitido.
  2. Escolha recuo de 2 espaços, 4 espaços ou tabulações.
  3. Selecione Formatar e validar JSON.
  4. Revise Resultado. Uma entrada válida gera JSON formatado; se for inválida, permanece em Entrada e mostra um diagnóstico quando há uma localização.
  5. Copie Resultado ou baixe o arquivo JSON formatado atual.

Como validar JSON online

  1. Cole ou carregue o JSON que deseja verificar.
  2. Selecione Validar JSON sem precisar formatar o texto.
  3. Procure o status JSON válido ou revise o diagnóstico de sintaxe.
  4. Se houver linha, coluna e contexto, use-os para corrigir Entrada e valide novamente.

Minificador JSON

Minificar JSON analisa uma entrada válida e a serializa como JSON compacto em uma única linha. A minificação remove espaços de formatação; ela não compacta o arquivo nem cria um ZIP ou outro formato de arquivo. O resultado atual pode ser copiado ou baixado.

Processamento local no navegador

A formatação, a validação, a minificação, a leitura de arquivos, a cópia e a preparação do download acontecem localmente no navegador. Durante essas operações, o JSON não é enviado para um servidor da aplicação nem armazenado remotamente por esta ferramenta.

Perguntas frequentes

Por que o erro aponta depois da vírgula que falta?

A posição indica onde o analisador não conseguiu continuar. Se a linha marcada parecer correta, confira o final da propriedade anterior. No exemplo inválido acima, a vírgula deve vir depois de "4all.tools".

Posso abrir um arquivo .json?

Sim. Selecione ou arraste um arquivo .json para a ferramenta. O texto aparece no editor, onde você pode conferir os dados antes de executar uma ação.

Sintaxe válida significa que meus dados estão corretos?

Não. Por exemplo, {"idade":"vinte"} é JSON válido, mas uma aplicação que espera uma idade numérica pode rejeitá-lo. Use um validador de JSON Schema para verificar campos obrigatórios, tipos ou outras regras dos dados.

Limitações da análise de JSON

Chaves duplicadas geram um aviso; ao formatar ou minificar, o último valor é mantido. Por exemplo, {"nome":"Ana","nome":"Beto"} vira {"nome":"Beto"}. A validação mostra o aviso sem reescrever a entrada. Remova duplicidades involuntárias antes de usar o resultado.

Inteiros muito grandes e decimais de alta precisão podem perder exatidão quando representados como números do JavaScript. Formatar ou minificar também altera espaços e pode mudar a escrita de números ou escapes. Guarde o original se esses detalhes forem relevantes.

O texto colado aceita até 5.242.880 unidades UTF-16. Documentos profundos ou complexos podem atingir os limites de processamento ou saída antes disso. Entrada vazia, um BOM UTF-8 inicial e números fora do intervalo aceito são rejeitados. JSON5, comentários, vírgulas finais, strings entre aspas simples, NaN, Infinity e undefined não são aceitos como JSON padrão. Escapes de substitutos isolados são aceitos com aviso.

Cancelar uma operação ou ter uma falha no download não significa, por si só, que o JSON seja inválido. Leia a mensagem específica antes de modificar o documento.
