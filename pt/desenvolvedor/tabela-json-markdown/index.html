Visualize um array JSON como tabela e exporte Markdown

Transforme um array de objetos JSON em tabela. Escolha colunas e linhas e copie ou baixe o Markdown para sua documentação.

Espaço de trabalho da ferramenta

Tabela JSON / JSON para Markdown

Ative JavaScript para usar esta ferramenta local.

Escolha explicitamente um array de objetos. Strings e cabeçalhos mantêm aspas JSON; quebras de linha aparecem como escapes. ∅ significa propriedade ausente, diferente de null e "". Objetos e arrays aparecem como JSON compacto; as colunas mantêm chaves literais e ordem da fonte.

O documento é processado localmente no navegador. A entrada não é enviada, carregada remotamente ou salva.

Arquivo: 4000000 bytes; entrada: 1000000 unidades UTF-16; profundidade: 200; nós: 100000; linhas: 20000; colunas descobertas: 200; posições de células incluídas: 75000.

Linhas a incluir

Texto de célula: 10000; cabeçalhos: 20000; linha: 100000; tabela: 1000000; Markdown: 2000000 unidades UTF-16. Nem todos os máximos são aceitos simultaneamente. Escolha menos colunas ou as primeiras N linhas para reduzir a saída.

      O tamanho da página altera apenas as linhas visíveis. Markdown exporta todas as linhas incluídas.

      O limite de largura ou texto reduziu esta página em relação ao tamanho escolhido.

      Tabela do array JSON selecionado

      Markdown exporta todas as linhas incluídas para tabelas GitHub Flavored Markdown. A pontuação ASCII usa entidades numéricas para preservar o texto. Um visualizador Markdown pode transformar URLs ou endereços de e-mail em links clicáveis. A fonte pode ser maior que a tabela visível. Markdown não é um formato reversível de JSON.

      A área de transferência está indisponível ou foi negada. Selecione e copie todo o Markdown no campo de saída ou tente Copiar novamente.

      Escolha os dados da tabela

      Cole JSON estrito ou abra um arquivo .json UTF-8 e pressione Analisar arrays. Selecione o array desejado, inclusive $ se o documento for um array, e pressione Inspecionar colunas. Todos os elementos precisam ser objetos, mesmo que você pretenda exportar apenas as primeiras linhas.

      A ferramenta procura colunas em todo o array, incluindo propriedades que aparecem apenas no final. Selecione pelo menos uma e use Mover para cima/baixo para ordenar. Os nomes são interpretados literalmente: um ponto na chave não indica um caminho aninhado. Objetos e arrays aninhados ficam juntos em uma célula.

      Um documento sem arrays não tem dados para converter em tabela. Um array vazio [], ou que contenha apenas objetos vazios, não tem colunas. Comentários, JSONC, JSON5 e chaves duplicadas são rejeitados.

      Valores ausentes, null e strings vazias

      [{"id":"00123","name":"Ana"},{"name":"Beto","active":true}]

      O exemplo produz as colunas id, name e active. A primeira linha contém "00123", "Ana" e ∅; a segunda, ∅, "Beto" e true.

      Os símbolos distinguem três casos: ∅ indica uma propriedade ausente, null é um valor nulo explícito e "" é uma string vazia. Strings e cabeçalhos mantêm as aspas JSON. Quebras de linha aparecem como escapes JSON, e valores aninhados usam JSON compacto.

      Os números preservam sua escrita, incluindo 1.0, 1e0, -0 e 9007199254740993. Um aviso de precisão não significa que o texto exibido foi arredondado; um número fora do intervalo aceito, como 1e999, é rejeitado.

      Exporte as linhas de que precisa

      Escolha todas as linhas ou as primeiras N e pressione Preparar tabela. N precisa ser um inteiro positivo. Essa seleção define a exportação; mudar de página não a altera. As páginas mostram até 10, 25 ou 50 linhas, com menos linhas quando as células contêm muito texto.

      Pressione Gerar Markdown para criar uma tabela compatível com GitHub Flavored Markdown. Caracteres que poderiam ser interpretados como formatação são codificados: uma barra vertical vira &#124; e aspas viram &#34;. Assim, HTML, imagens e Markdown presentes nos dados são exibidos como texto. Um visualizador Markdown ainda pode transformar URLs ou e-mails em links.

      Copiar e baixar incluem todas as linhas selecionadas. O arquivo é json-table.md, em UTF-8 sem BOM, com quebras LF e uma quebra final. Se a área de transferência falhar, use a cópia manual. Confira o resultado no visualizador que pretende usar: os dialetos variam, e a tabela não permite reconstruir o JSON original.

      Limites e processamento local

      Limite Máximo
      Arquivo 4.000.000 bytes
      Entrada 1.000.000 unidades UTF-16
      Contêineres aninhados / valores JSON 200 níveis / 100.000
      Linhas de origem / colunas 20.000 / 200
      Posições de células selecionadas 75.000
      Texto por célula 10.000 unidades UTF-16
      Tabela completa / Markdown 1.000.000 / 2.000.000 unidades UTF-16

      Cabeçalhos longos, linhas grandes ou estruturas complexas podem atingir outros limites de processamento antes. Em caso de erro, a ferramenta não corta células nem entrega uma tabela parcial. Se o Markdown ultrapassar seu limite, a tabela preparada continua disponível, mas não há exportação parcial.

      O processamento usa um Worker local e requer JavaScript. Entrada e saída não são enviadas nem salvas. Os arquivos devem usar UTF-8; um BOM inicial é removido com aviso, enquanto um segundo é rejeitado.

      Se mudar a entrada, o array, as colunas ou a seleção de linhas, prepare a tabela novamente. Cancelar mantém a entrada; ao tentar de novo, ela será analisada outra vez.
