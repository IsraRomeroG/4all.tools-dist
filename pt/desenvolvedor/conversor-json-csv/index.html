Converta JSON e CSV no navegador

Converta matrizes de objetos JSON para CSV ou inspecione cabeçalhos CSV e transforme linhas em JSON com opções explícitas de tipos e linhas irregulares.

Espaço de trabalho da ferramenta

Converter JSON para CSV e CSV para JSON

Direção da conversão

Escolha uma matriz de objetos após inspecioná-la. A entrada não é modificada.

Exemplo reproduzível

{
  "people": [
    { "name": "Ada", "active": true, "score": 42 },
    { "name": "Grace", "score": null }
  ]
}

Seleção de matriz

Colunas CSV

    Para uma matriz vazia, adicione um ou mais nomes de coluna exclusivos.

          Converta matrizes de objetos JSON para CSV
          

          Cole um documento JSON ou carregue um arquivo local .json e escolha Inspecionar matrizes. Os caminhos e as quantidades de linhas aparecem em páginas de até 200 matrizes. Escolha uma matriz para inspecionar a união completa das chaves dos objetos. Chaves que aparecem apenas em linhas posteriores também são incluídas:
          

          {"pessoas":[{"nome":"Ada"},{"nome":"Grace","cidade":"Lisboa"}]}
          

          Reordene as colunas com os botões Mover para cima e Mover para baixo. Uma matriz vazia não tem chaves para inspecionar; adicione nomes de coluna exclusivos antes de convertê-la. Escolha vírgula, ponto e vírgula ou tabulação como delimitador, finais de registro LF ou CRLF e se deseja adicionar um BOM UTF-8.
          

          CSV não tem tipos JSON. Números, booleanos, null, propriedades ausentes e strings vazias podem virar células vazias ou textuais indistinguíveis. Uma exportação de uma coluna mantém explícita a última célula vazia:
          

          nome
Ada
""
          

          Inspecione CSV antes de escolher os tipos JSON
          

          Cole texto CSV ou carregue um arquivo local .csv; escolha o delimitador e a política de campos extras antes de Inspecionar CSV. Os cabeçalhos precisam ser exclusivos e não vazios. Depois da inspeção, escolha um tipo para cada cabeçalho, inclusive os gerados. Não há inferência: cada coluna continua como texto até você selecionar número ou booleano.
          

          Por exemplo, 00123 permanece a string "00123" por padrão. Uma linha curta omite a propriedade ausente por padrão. Uma linha longa falha com a política padrão Rejeitar; Estender adiciona nomes como column_3 para os campos extras. Células vazias podem permanecer strings, virar null ou ser omitidas. Você também pode escolher se linhas curtas omitem ou preenchem valores ausentes.
          

          O leitor CSV aceita campos entre aspas, aspas duplicadas escapadas, delimitadores entre aspas e células multilinha entre aspas. A entrada pode usar LF ou CRLF. Uma assinatura BOM UTF-8 inicial é removida para análise e gera um aviso.
          

          Proteção de fórmulas e texto exato
          

          Por padrão, um apóstrofo é prefixado ao texto CSV iniciado por =, +, - ou @ para reduzir o risco de execução de fórmulas em planilhas. Isso pode alterar o texto exato. Desative a proteção para exportar texto exato. Se a proteção tornar dois cabeçalhos idênticos, o conversor informa HEADER_PROTECTION_COLLISION e não cria resultado; escolha texto exato ou edite os cabeçalhos de origem e tente novamente.
          

          JSON para CSV também pode avisar sobre perda de informação de tipos JSON ou de precisão numérica. Confira esses avisos quando o CSV for usado como dados e não apenas exibido em uma planilha.
          

          Limites do navegador e privacidade
          

          Os limites de arquivo de 4 MiB, 1.000.000 de unidades UTF-16 de entrada, 2.000.000 de saída, 20.000 linhas de dados, 200 colunas, 100.000 unidades por célula, 75.000 posições de células de dados e 20.000 unidades de prévia mantêm o processamento limitado. A prévia não é a saída completa: Copiar tudo e Baixar solicitam o resultado retido somente depois da ativação do botão correspondente. Uma prévia truncada nunca é copiada como saída completa.
          

          A análise e a conversão são executadas em um Web Worker local. A entrada não é enviada a um servidor, colocada na URL ou salva no armazenamento do navegador. Os erros mostram caminhos JSON ou linha lógica, campo e linha/coluna físicas do CSV quando disponíveis. Editar a entrada ativa limpa o resultado; cancelar interrompe a operação do Worker sem alterar a entrada.
