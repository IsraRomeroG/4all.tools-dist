4all.tools

Useful online tools for everyday work.

Available tools

  • JSON / SQL Converter

    Convert flat JSON rows to a documented PostgreSQL or SQLite SQL subset, or import supported CREATE TABLE and INSERT literals as JSON.

  • JSON ↔ XML Converter

    Convert strict JSON and an XML 1.0 data subset locally, with explicit roots, attributes, repeated elements and visible loss notices.

  • JSON ↔ YAML Converter

    Convert strict JSON to YAML or a JSON-compatible YAML subset to JSON, preserving member order and numeric spelling in your browser.

  • JSON Diff

    Compare two strict JSON documents by value. Review added, removed, and changed values with localized diagnostics and bounded previews.

  • JSON Flatten / Unflatten

    Convert strict JSON to reversible dot or bracket paths and reconstruct it locally, preserving empty values and numeric tokens while rejecting ambiguous maps.

  • JSON Formatter & Validator

    Format, beautify, and validate JSON online. Detect syntax errors and make JSON data easier to read.

  • JSON Repair

    Convert JSONC comments and trailing commas to strict JSON, or attempt a bounded heuristic repair and review every text change.

  • JSON Schema Generator

    Infer a shared JSON Schema from one to twenty JSON samples, review required fields and check every complete document locally.

  • JSON Schema Validator

    Check a strict JSON document against a local, explicitly limited subset of JSON Schema draft-07.

  • JSON Search

    Find literal text in strict JSON keys and primitive values, then copy the path or locate the original value in your browser.

  • JSON Size Analyzer

    Measure exact UTF-8 bytes, UTF-16 length, node counts, arrays and paths with local analysis of strict JSON.

  • JSON Sort Keys

    Sort strict JSON keys ascending or descending, recursively or at the root, while preserving arrays and original numeric tokens locally.

  • JSON Table / JSON to Markdown

    Choose an array of objects, select literal columns and export a safe GFM Markdown table locally in your browser.

  • JSON to C#

    Infer C# classes locally with exact JSON property names, JsonRequired presence and explicit nullable and raw-number capabilities.

  • JSON to CSV Converter

    Convert arrays of JSON objects to CSV or inspect CSV headers and convert rows to JSON, with explicit type and irregular-row choices.

  • JSON to Go

    Infer Go structs and raw maps locally, preserve lexical numbers with json.Number and explain optional pointer capabilities.

  • JSON to Python

    Infer Python TypedDict declarations locally, preserve exact dictionary keys and separate absent fields from None.

  • JSON to TypeScript

    Infer TypeScript types from complete JSON documents, preserve literal keys and distinguish missing fields from null locally.

  • JSON Tree Viewer

    Explore strict JSON as a bounded, expandable tree. Inspect value types, browse large arrays in pages, and copy a selected JSON path while your input stays in your browser.

  • JSONPath Finder

    Search a strict JSON document with a supported JSONPath query, inspect matching paths and previews, and copy a selected path or value in your browser.
